# HW-002 — DM_In 掉电时驱动供电衰减与下管栅极渐降

- **状态：OPEN**
- **首次记录：2026-11-16**
- **关联阶段：V0.1-A5，辅助电源失电 / Gate 默认关断**
- **硬件：LKS32MC071CBT8 + LKS_EVB_MVPOWPRE_V5.0，LKS560 驱动器（依据既有原理图记录）**
- **当前决定：先保留完整实测与不确定性；暂不改动当前板卡，不宣称已解决掉电快速关断。**

## 现象与数据

在既有 A5 低能量台架条件下，关闭独立 DM_In 供电的 Output，主功率母线不供电、电机断开，观测到：
1. +15V（LKS560 VCC）与 +5V 电源轨下降，下降并非瞬时。
2. 受测 U 相下管此前处于导通状态，`VGS=CH1(Gate)−CH2(Source)` 从约 15V 经明显渐降阶段到 0V 附近；在约 20ms/div 截图上呈数十毫秒量级趋势，**未测得准确延时**。
3. 复测时已拔掉 J-Link，供电轨/VGS 的缓慢下降仍可见。J-Link 不是此现象的充分解释，但未全面排除其它供电路径。
4. 用户万用表读数（按本轮提问对应测点）：DM_In Output OFF 约 5s 后，+15V/GND ≈1.2V，+5V/GND ≈0.2V。DM_In 残余电压及长时间稳态未报告。
5. 本轮已观察的 U/V/W 三相 HIN/LIN 输入交接没有出现双请求有效（CH1=LIN，CH2=HIN），**与掉电时硬件关断是不同的验收项目**。

本轮没有主母线带电试验，没有电机负载。原始截图提供于 ChatGPT 对话，本公开仓库只写文字归纳；**未声称原始 PNG 已存入 `hardware/measurements/raw`**。

## 影响及不确定性

- **已观察**：当前受测下管掉电后最终 VGS 接近 0V。
- **未证实**：所有桥臂在 MCU 高阻/掉电、LKS560 VCC 缓降或欠压期间均有独立可靠的硬件关断；失电过程中是否经历 MOS 部分导通；有功率母线时的风险等级。
- **待核实原因**：驱动输出随 VCC 衰减、UVLO 时序、MCU 5V 掉电行为、LIN 默认上拉/下拉、各供电轨残压与电容放电路径、外部电源反灌。上述仅为候选解释，**不认定根因**。
- 当前观测不能支持立即决定 RC 参数、栅极电阻值或断电主动放电电路结构。

## 后续判定条件（先逻辑级，禁止带主母线）

1. 断电核实 DM_In/+15V/+5V 的实际路径、P3 与 J-Link/USB 接线情况、LIN/HIN 外部默认上下拉。
2. 依据实际 LKS560 数据手册核对输入随 VCC 下降的允许范围、UVLO 触发及输出状态。
3. 在母线 0V、无电机的条件下设计**同步**的 VCC/LIN/下管 VGS 下降测试，并将时间游标定量；确认默认停机和正在导通两种状态。需先确认共地测量方案不会跨接 R69 或短接节点。
4. 必要时补充另外两相、上电恢复、供电快速中断等边界情形，但不得为加快验收而直接用主母线电压制造失电故障。
5. 若证据表明失电期间不能可靠关断，升级为硬件/固件整改，必要时在下一版 PCB 预留电源监控、使能与栅极下拉候选位置；**未经实验不冻结具体方案**。
