# HW-002 — DM_In 断电时供电衰减及下管 VGS 渐降

- **状态：OPEN**
- **首次记录：2026-11-16；关联阶段：V0.1-A5**
- **硬件：**LKS32MC071CBT8 + LKS_EVB_MVPOWPRE_V5.0 / LKS560（沿用原理图硬件基线）
- **处理原则：** 先追踪风险与验证条件，不因单次慢降就立即改电阻、RC或PCB；不得据此放行带功率测试。

## 可重复追溯的现象摘要

低能量隔离台架、主母线不供电、电机不接时，U相**低侧原先处于导通**，关闭DM_In后：
- U相 `VGS` 从约15V经缓慢衰减最终趋近0V；截图为数十毫秒量级趋势，**无准确游标关断延时**。
- +15V与+5V随电源输出关闭而下降；拔除J-Link后仍有相似现象。约5秒残压：+15V≈1.2V、+5V≈0.2V（用户万用表反馈；DM_In及更长时刻未提供）。
- **停止状态**六管上电/断电/重新上电无持续误开启，另有用户确认；它和本次**导通中失电**不是同一验收工况。

**详细截图条件、数据、限制统一在[11-16 A5实测报告](../../tests/reports/2026-11-16_V01-A5-input-interlock-powerdown.md)**，避免在 Issue 复制原始报告。输入边沿负向过冲另归[HW-001](HW-001-mcpwm-edge-ringing.md)，两者目前未证明同源。原始PNG在对话中提供，尚未核实已进入私有raw目录。

## 未解决的安全问题

1. MCU 5V 与驱动15V下降的先后关系、LIN低有效输入在高阻与欠压期间的默认态及逻辑电平合法性。
2. LKS560 UVLO/输出状态与MOS栅极放电路径：**最终关断已观察到，独立快速关断没有证明**。
3. 其余各相的导通中失电、复位纳秒瞬态、在真正有母线电压/电机回馈时的适用性尚未验证。
4. 若将来证明掉电会导致不可接受的部分导通/误导通，才评审独立Gate关断、电源监控或PCB选配网络；目前**不宣称根因**。

## 再验证门槛

- 先做断电下的输入上下拉/供电拓扑审计，核对芯片正式数据手册的UVLO与输入边界。
- 主母线仍为0V、电机仍断开时，在安全测量参考已确认后设计可同步的15V/5V/LIN及实际VGS时序采集，记录关断电压阈值和时间；不能将不同次采集相减当真实关断延迟。
- 在确认原因和影响之前保留 **OPEN**；A5可以推进V0.2控制板逻辑级研究，但不得作为功率母线与电机试验的安全放行依据。
