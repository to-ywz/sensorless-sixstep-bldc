# Hardware Issues

记录当前硬件上已经观察到、尚未解决或需要下一版 PCB 处理的问题。

## 状态定义

- **OPEN**：问题已确认存在，仍需分析或验证。
- **DEFERRED**：当前硬件不便修改，保留到下一版硬件处理；不代表风险已消除。
- **MITIGATED**：已有措施降低影响，但尚未完整关闭。
- **CLOSED**：根因和解决措施已验证，并在目标硬件版本完成验收。
