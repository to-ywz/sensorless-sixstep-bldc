# HW-001 — MCPWM 输出边沿振铃与负向过冲

- **状态：OPEN / DEFERRED TO NEXT BASEBOARD REVISION**
- **首次记录：2026-11-08**
- **关联阶段：V0.1-A2，CH0P/CH0N 互补 PWM 逻辑级验证**
- **关联硬件：LKS32MC071CBT8 控制板、LQ9101 预驱输入级**
- **当前处理：记录问题，不改动现有底板；在下一版自绘底板时评估阻尼/滤波设计。**

## 1. 现象与实测记录

A2 互补 PWM 工作时，在数字信号边沿观察到正向过冲、负向下冲及衰减振铃。振铃主要集中在边沿附近，随后快速衰减；当前没有观察到它形成额外的 PWM 逻辑脉冲。

本轮已改进测量方法，并分别在 MCU 端和预驱输入端测量：

| 测量位置 | 探头参考点 | 接地方式 | 观察到的负向最低值 |
|---|---|---|---:|
| MCU P1.4 / CH0P | MCU 本地 GND | ×10 探头，短弹簧地 | 约 **-0.8 V** |
| 预驱输入端 | 预驱本地 GND | ×10 探头，参考预驱本地地 | 约 **-1.2 V** |

补充记录：
- 两处波形均可见边沿振铃，量级相近；预驱输入端记录到的负向峰值更低约 0.4 V。
- 正向过冲也有观察到，但本次没有记录可靠的正向峰值数值。
- 示波器：RIGOL DHO914；截图显示约 20 ns/div、1.25 GSa/s、2 V/div。探头为 ×10。
- 使用普通长地线时，尖峰更明显；改用短弹簧地、缩短测量回路/信号连接后，观察到的振铃幅度减小。
- A2 PWM 载波约 10.1 kHz；当前逻辑级死区配置为 48 个 MCPWM 计数，实测约 1 µs。
- 当次预驱输入测量时，IN 节点是否始终由 MCU 直接驱动、输入网络是否完整连接，需在后续复测记录中明确。不要把未确认负载状态的测量当作最终应用工况。

## 2. 当前判断

目前只能确认**测量点上观察到了边沿瞬态振铃**，尚未完成根因分离，不能断言全部来自探头，也不能断言全部来自 PCB。

待验证的可能因素：
1. MCU GPIO 较快的边沿与 PCB 走线、连接线的寄生电感/电容形成欠阻尼响应。
2. 信号与 GND 回流路径的环路面积、共地阻抗及局部地弹。
3. LQ9101 输入端的输入电容、输入偏置/钳位结构及连接线寄生参数。
4. 探头接地回路仍有残余寄生参数；弹簧地能减小但不能完全消除测量误差。

缩短连接后振铃变小，说明互连几何和回流路径值得在下一版 PCB 中优化，但尚不足以单独锁定根因。

## 3. 风险与验证边界

- MCU 端记录的约 -0.8 V、预驱输入端记录的约 -1.2 V，均应视为**待核对绝对最大额定值的负向瞬态**，不能因为持续时间短就默认安全。
- 后续需分别对照 LKS32MC071 数据手册的 GPIO 引脚电压/注入电流限制，以及 LQ9101 数据手册的输入引脚绝对最大额定值。
- 现有照片没有给出可靠的正向过冲峰值；需补测 Vmax/Vmin，不能仅凭屏幕网格估读后判定是否满足额定值。
- 目前没有证据表明 MCU 或预驱已经损坏，也没有完成长期可靠性验证。
- 在电压边界和预驱输入工况未核实前，本记录不构成功率级安全验收。可以继续进行母线断电、电机断开的 MCU 逻辑级验证；不要据此认定预驱/功率级已经通过。

## 4. 当前硬件处理决定

现有底板不便插入串联阻尼电阻，当前阶段不强行飞线修改，也不为了追求“波形绝对无振铃”而中断整个软件验证。

本问题保持 OPEN / DEFERRED：
- 保留现有波形和实测数值。
- 现有板继续用于受控的逻辑级验证。
- 不把该问题标记为已解决。
- 后续若有条件复测，优先补齐 Vmax/Vmin、IN 端实际连接状态及探头接法。

## 5. 下一版自绘底板的候选改进

以下均为**设计候选项，不是已经验证的解决方案**：

### 5.1 预驱输入端预留可选 RC 滤波位置

在 LQ9101 每路逻辑输入附近预留串联电阻和对本地逻辑 GND 的电容焊盘，默认可 DNP/0Ω 配置，方便后续比较：
- 不装电容；
- 仅串联阻尼电阻；
- 串联电阻 + 小电容构成 RC 滤波。

具体阻值、电容量暂不指定。必须根据 LQ9101 输入阈值、输入电容、最小脉宽、传播延迟、PWM 频率及允许的有效死区变化计算并实测。RC 过大可能增加边沿延迟、改变脉宽，甚至压缩有效死区；不能只以振铃幅度最小作为选值标准。

### 5.2 MCU 输出端预留串联阻尼电阻

每路 MCU PWM 到预驱输入的信号线上，靠近 MCU 端预留串联电阻封装，支持 0Ω、不同阻值的替换实验。实际阻值由板级波形和预驱输入时序决定。

### 5.3 优化信号回流与可测性

- PWM 信号与连续、低电感的逻辑 GND 回流路径相邻布线。
- 缩短信号线及连接器到预驱输入的路径，减小环路面积。
- 避免 PWM 信号长距离贴近开关节点和高 di/dt 功率回路。
- MCU 端和预驱输入端分别预留相邻的信号/GND 测试点，便于弹簧地或同轴方式测量。
- 确保预驱输入滤波电容的回流接到正确的预驱逻辑参考地，不随意跨接功率地/开关节点。

## 6. 关闭条件

满足以下条件后才能将问题关闭：
1. 在明确的探头与接地条件下复测 MCU 端和预驱输入端。
2. 记录两处 Vmax、Vmin、振铃持续时间及输入连接状态。
3. 核对 MCU 与 LQ9101 的绝对最大额定值、输入阈值和注入电流要求。
4. 若采用阻尼/RC 改动，验证高低电平、上升/下降时间、最小脉宽、两方向有效死区及温度/电压条件。
5. 在目标硬件版本上完成复测并保留证据。
