# Hardware

记录首版控制核心板、功率底板、电机和测试连接。

## 当前基线
- MCU：LKS32MC071CBT8
- Power board：LKS_EVB_MVPOWPRE_V5.0（待实物版本复核）

## 目录
- boards：板卡说明、引脚、信号、采样和保护链路。
- schematics：仅放公开且获授权的原理图索引；原始文件默认不提交。
- bom：公开可披露的关键器件信息。
- measurements：脱敏测量方法与结果。
- reference：数据手册和外部资料链接。

## 安全提示
在母线额定值、隔离方式、放电路径、功率器件额定值和保护链路未确认前，不得上高压或连接真实电机进行功率测试。
