# LKS_EVB_MVPOWPRE_V5.0 跨板信号映射（V0.0 原理图审计）

依据：LKS_EVB_MVPOWPRE_V5.0.PDF 与 LKS_EVB_MCU071CBT8_V1.0.PDF，第 1 页。状态为原理图追踪，尚未实物验证。

## 1. 三相功率桥

- U：核心板 UP/UN -> P1-22/7 -> 功率板 U_P/U_N -> LKS560 U1 HIN/LIN -> NCE8259AK U 相高低侧。
- V：核心板 VP/VN -> P1-21/6 -> 功率板 V_P/V_N -> LKS560 U2 HIN/LIN -> NCE8259AK V 相高低侧。
- W：核心板 WP/WN -> P1-20/5 -> 功率板 W_P/W_N -> LKS560 U5 HIN/LIN -> NCE8259AK W 相高低侧。

图纸使用 +48V、+15V、+5V 电源网络名；+48V 不是 FN550-90K 已确认额定电压。当前用户电源条件最高 32V，仍须核实功率板实际工作范围和辅助电源条件。

## 2. 三相 BEMF 分压及 ADC

| 电机相端 | 功率板串联电阻 | 功率板输出 | 核心板输入网络 | MCU |
|---|---|---|---|---|
| UX | R1=20k + R55=20k | PU（P1-4） | R18=1k、C4=1nF 到 GND | P0.13 / ADC1_CH13 |
| VX | R2=20k + R59=20k | PV（P1-3） | R19=1k、C5=1nF 到 GND | P0.12 / ADC1_CH12 |
| WX | R3=20k + R61=20k | PW（P1-17） | R20=1k、C6=1nF 到 GND | P0.11 / ADC1_CH11 |

简化静态比例约为 1/41，仅为理想电阻网络估算，需实测校准。三相 BEMF 需要合适的虚拟中点/参考阈值；三路对 GND 分压并不等于已形成虚拟中性点。

## 3. 三相电流采样选择

功率板低侧采样电阻：
- R15：U 相，0.005Ω/2512。
- R16：V 相，0.005Ω/2512。
- R17：W 相，0.005Ω/2512。

P5/P6/P7 三组 3-pin 选择接口，图纸标注 P-X 为采样 MOS 内阻、P-I 为采样电阻：

| Header | Pin 1 | Pin 2（送核心板） | Pin 3 |
|---|---|---|---|
| P5 | UX | UP | UI |
| P6 | VX | VP | VI |
| P7 | WX | WP | WI |

预期跳帽 1-2 选择 MOS 内阻采样（P-X），2-3 选择对应 5mΩ 采样电阻（P-I）。**用户确认当前板卡使用三电阻采样（P-I），即 U/V/W 分别使用 R15/R16/R17。** 实际跳帽位置仍建议拍照和断电通断确认，作为实物证据。**此跳帽只切换相电流采样信号源（MOS Rds(on)/分流电阻），不切换单/双/三 Shunt 功率拓扑。**

核心板运放输入映射：
- UP- -> OPA2_IP/IN（U 相）。
- VP- -> OPA1_IP/IN（V 相）。
- WP- -> OPA0_IP/IN（W 相）。

## 4. 公共 PGND-GND 电流采样

- 功率板 R69 = 0.005Ω/2512，图纸标注“采样电阻（合金）”，位于 PGND 与 GND 之间。
- 核心板 OPA3_IP 通过 R13=1k 接 PGND，并有 C7=1μF 滤波；OPA3_IN 通过 R14=1k 接 GND。
- 这构成跨 PGND-GND 的公共回流电压检测候选通路。CE1 220μF 的负端接 GND，CE2 220μF 及 C25~C27 各 100nF 的负端接 PGND，局部电容电流可能绕过 R69；实际瞬时电流覆盖须核对功率入口、PCB 和动态回流。

## 5. DM_In 辅助电源电压采样（非独立主母线采样）

功率板 DM_In -> R74=20k + R75=20k -> Vol_ADC；核心板 Vol_ADC 下拉 R23=1k、C8=100nF 到地；MCU P2.9 / ADC0_CH12。简化静态比例约 1/41，实际需校准。**P3 断开且 DM_In 单独供电时，Vol_ADC 不是 +48V 功率母线电压**；下一版需区分两者。

## 6. 外部 OC 与接口差异

- 核心板 OC 网络连接 P2.1 / CMP1_IP0；功率板 P2 接口也标注 OC。**CMP1 原始输出可经内部 MCPWM0_FAIL012.FAIL1 保护 CH0/1/2（寄存器映射已核对）**，但必须先追踪 OC 的实际来源、极性、幅度、滤波和响应时间。仅有 OC 网络名不能证明已实现逐波 OCP。
- 两份原理图 P2-5、P2-18 的网络标签存在差异，需断电核实实际连接。
- 功率板含 LKS620 辅助电源与 LM7805；非隔离边界未经确认前，不做市电接入测试。


## 7. 曾提出但已取消的拆焊 / 飞线方案（历史纠错）

**当前不拆板、不过线、也不改变 BEMF 模拟输入。**

- 历史上曾因误认为 CMP1 只能对 MCPWM CH3 起作用，而提议将 CMP0 改为 OCP、BEMF 改接到 CMP1 的 Hall 网络。这产生过拆功率板 Hall 上拉 R51/R52/R53、拆核心板 Hall 滤波 C1/C2/C3、PU/PV/PW 飞线等建议。
- 该前提已经纠正：`MCPWM0_FAIL012.FAIL1_SEL=1` 具有 CMP1_RAW→FAIL1→CH0/1/2 内部候选通路。**保留 CMP0 检测 BEMF，优先验证 CMP1 用于 OCP。** 因此原 Hall 拆件/飞线内容从现行映射文档撤销；历史详情可通过 Git 提交记录追溯。
- P2.5→P2.3/BKIN0 是内部通路实测受阻后才评估的独立备选；P2.5→P0.0 属错误建议，P0.0 不支持 BKIN0。
- 当前 PU/PV/PW 已分别连 CMP0_IP3/IP2/IP1 (P0.13/P0.12/P0.11)，无须为此交换比较器。版本与实际连通仍待无电核查。
- 参见 [当前保护链路](protection_chain.md) 与 [下一版单/双/三电阻兼容板](next_revision.md)。
