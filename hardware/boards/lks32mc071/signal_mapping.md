# LKS_EVB_MVPOWPRE_V5.0 跨板信号映射（V0.0 原理图审计）

依据：LKS_EVB_MVPOWPRE_V5.0.PDF 与 LKS_EVB_MCU071CBT8_V1.0.PDF，第 1 页。状态为原理图追踪，尚未实物验证。

## 1. 三相功率桥

- U：核心板 UP/UN -> P1-22/7 -> 功率板 U_P/U_N -> LKS560 U1 HIN/LIN -> NCE8259AK U 相高低侧。
- V：核心板 VP/VN -> P1-21/6 -> 功率板 V_P/V_N -> LKS560 U2 HIN/LIN -> NCE8259AK V 相高低侧。
- W：核心板 WP/WN -> P1-20/5 -> 功率板 W_P/W_N -> LKS560 U5 HIN/LIN -> NCE8259AK W 相高低侧。

图纸使用 +48V、+15V、+5V 电源网络名；+48V 不是 FN550-90K 已确认额定电压。当前用户电源条件最高 32V，仍须核实功率板实际工作范围和辅助电源条件。

## 2. 三相 BEMF 分压及 ADC

| 电机相端 | 功率板串联电阻 | 功率板输出 | 核心板输入网络 | MCU |
|---|---|---|---|---|
| UX | R1=20k + R55=20k | PU（P1-4） | R18=1k、C4=1nF 到 GND | P0.13 / ADC1_CH13 |
| VX | R2=20k + R59=20k | PV（P1-3） | R19=1k、C5=1nF 到 GND | P0.12 / ADC1_CH12 |
| WX | R3=20k + R61=20k | PW（P1-17） | R20=1k、C6=1nF 到 GND | P0.11 / ADC1_CH11 |

简化静态比例约为 1/41，仅为理想电阻网络估算，需实测校准。三相 BEMF 需要合适的虚拟中点/参考阈值；三路对 GND 分压并不等于已形成虚拟中性点。

## 3. 三相电流采样选择

功率板低侧采样电阻：
- R15：U 相，0.005Ω/2512。
- R16：V 相，0.005Ω/2512。
- R17：W 相，0.005Ω/2512。

P5/P6/P7 三组 3-pin 选择接口，图纸标注 P-X 为采样 MOS 内阻、P-I 为采样电阻：

| Header | Pin 1 | Pin 2（送核心板） | Pin 3 |
|---|---|---|---|
| P5 | UX | UP | UI |
| P6 | VX | VP | VI |
| P7 | WX | WP | WI |

预期跳帽 1-2 选择 MOS 内阻采样（P-X），2-3 选择对应 5mΩ 采样电阻（P-I）。**用户确认当前板卡使用三电阻采样（P-I），即 U/V/W 分别使用 R15/R16/R17。** 实际跳帽位置仍建议拍照和断电通断确认，作为实物证据。

核心板运放输入映射：
- UP- -> OPA2_IP/IN（U 相）。
- VP- -> OPA1_IP/IN（V 相）。
- WP- -> OPA0_IP/IN（W 相）。

## 4. 公共 PGND-GND 电流采样

- 功率板 R69 = 0.005Ω/2512，图纸标注“采样电阻（合金）”，位于 PGND 与 GND 之间。
- 核心板 OPA3_IP 通过 R13=1k 接 PGND，并有 C7=1μF 滤波；OPA3_IN 通过 R14=1k 接 GND。
- 这构成跨 PGND-GND 的公共回流电压检测候选通路；实际是否覆盖全部主电流，须核对功率入口及 PCB 回流路径。

## 5. 母线采样

功率板 DM_In -> R74=20k + R75=20k -> Vol_ADC；核心板 Vol_ADC 下拉 R23=1k、C8=100nF 到地；MCU P2.9 / ADC0_CH12。简化静态比例约 1/41，实际需校准。

## 6. 外部 OC 与接口差异

- 核心板 OC 网络连接 P2.1 / CMP1_IP0；功率板 P2 接口也标注 OC。该信号进入 CMP1 输入候选，但 CMP1 的 MCPWM Fail 映射面向 CH3，不能直接视为三相 CH0/1/2 的 OCP。
- 两份原理图 P2-5、P2-18 的网络标签存在差异，需断电核实实际连接。
- 功率板含 LKS620 辅助电源与 LM7805；非隔离边界未经确认前，不做市电接入测试。


## 7. CMP1 BEMF 输入复用评估（路线 A）

### 现有连接
- 当前三相分压输出 PU/PV/PW 分别送到核心板 P0.11/P0.12/P0.13，即 CMP0_IP1/IP2/IP3，同时也是 ADC1_CH11/12/13。
- 因此现有 BEMF 过零模拟输入属于 CMP0，不是 CMP1。
- LKS32MC071CBT8 的 CMP1_IP1/IP2/IP3 分别复用 P2.4/P2.5/P2.6；核心板原理图将其接到 HALL_W/HALL_V/HALL_U，并引至 P2 连接器。传感器无 Hall 时，这组网络可评估为 BEMF1 输入通道，但要先确认连接器 pin-to-pin 和实际板卡版本。
- 功率板 Hall 接口 P8 的 R51/R52/R53=2kΩ 将 HALL_U/V/W 上拉到 5V。若把 PU/PV/PW 通过 P2/HALL 线送入 CMP1_IP1/2/3，必须先隔离/移除这些上拉，或将其完整纳入分压比例和共模偏置计算并实测验证；不得未经计算直接并接后上电。

### 候选改线
- PU -> CMP1_IP1（P2.4/HALL_W）
- PV -> CMP1_IP2（P2.5/HALL_V）
- PW -> CMP1_IP3（P2.6/HALL_U）

以上为逻辑对应建议，最终相序映射要按连接器实物和 BEMF 波形确认；三相交换不会改变虚拟中点原理，但会影响软件相序表。

改线验收：
1. 断电检查 R51/R52/R53 的 5V 上拉；优先隔离/移除，若保留则先计算新分压比例与共模偏置并验证三路匹配。
2. 断电确认 PU/PV/PW 与 CMP1_IP1/2/3 之间无短接、无错误交叉。
3. 用限幅低压模拟信号验证 CMP1 三个正端输入选择。
4. 检查原 CMP0_IP1/2/3 的 ADC 采样路径仍然可用；若 CMP0 改作电流比较，其原 BEMF 输入选择不再用于零点检测。
