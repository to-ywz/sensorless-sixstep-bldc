# 下一版 PCB 设计候选与验证依据（LKS32MC071 / 单、双、三电阻兼容六步）

- 状态：**DESIGN CANDIDATE / NOT VERIFIED**。这是下一版 PCB 的评审清单，不是已批准的改板方案、当前实物缺陷结论或可直接执行的上电指令。
- 目标：**下一版通用验证 PCB 支持单 / 双 / 三电阻三种装配配置**，优先验收单电阻无感六步采样与可靠硬件逐波过流保护；后续产品板可据结果精简。现有三相 shunt 板作为 V0.2 对照平台，暂不拆件或更改现有 A5 测试条件。
- 所属流程：新 PCB 设计时纳入 [P0 设计审核](../../../docs/validation/sop.md)，完成后按 P1～P4 验收；当前 V0.2 实验提供设计证据。

## 1. 本次讨论的硬件事实与限制

依据所提供的 `LKS_EVB_MVPOWPRE_V5.0.PDF` 第 1 页原理图（文件本身不上传至 Public 仓库；PCB 图框/实物修订号仍需核对）：

| 器件 / 网络 | 原理图连接 | 对下一版的意义 |
|---|---|---|
| R15 / R16 / R17 | U / V / W 低侧，各 5mΩ | 现有三相低侧采样，用于对照；并非任意时刻都能还原真实相电流 |
| R69 | PGND ↔ GND，5mΩ | 公共回流 shunt 候选；检查是否存在绕行铜皮或外部返回路径 |
| CE1 | +48V ↔ GND，220μF | GND 侧母线储能电容 |
| CE2 | +48V ↔ PGND，220μF | PGND 侧局部电容放电可能绕过 R69；不能据此断言所有 PWM 电流都绕过 |
| C25 / C26 / C27 | +48V ↔ PGND，各 100nF | 高频去耦，需要保留低电感开关回路 |
| OPA3 输入前端（核心板） | R13/R14 各 1kΩ、C7 约 1μF | 简化差分 RC 时间常数约 2ms，不能直接视为适合 PWM 周期采样 / 快速 OCP |
| Vol_ADC | 现有图纸来自 DM_In 而非直接来自 +48V | P3 断开、辅助电源独立供电时可能不能代表真实功率母线电压 |

上表为原理图层面的连接事实与工程推断；**R69 是否位于全部目标功率电流路径、动态电流分配、板级布局/连接器造成的旁路，均尚未通过实测确认**。注意 V5.0 原理图中三只 +48V→PGND 的 100nF 是 C25～C27，不应与自举支路 C28～C30 混淆。

## 2. V0.2 先取得的证据（下一版设计输入）

1. **电流对照：** 同步记录 R69、R15/R16/R17、PWM 状态与扇区；按六扇区分别区分 PWM 导通、关断续流、换相瞬态，并尽可能以独立电流测量校核。低侧 shunt 自身也有采样盲区，不能无条件作为连续相电流真值。
2. **R69 / 电容回流：** 核对电源负端、CE1/CE2 负端、R69 两端、全部层铜皮、过孔、Net Tie、接插件、控制板及仪器可能形成的旁路；观察 CE2 动态充放电对 R69 瞬时读数的影响。
3. **前端带宽：** 通过安全的低压阶跃/受控注入验证 R69→OPA3→ADC/CMP1 的增益、零点、极性、建立时间、噪声及采样窗口；2ms 为一阶粗估，不以计算代替实测。
4. **硬件保护：** 先在主母线不供电、功率级安全禁能时验证 CMP1→FAIL1→MCPWM→正确 Gate 关断极性、延迟、锁存及恢复；随后在通过安全门槛的受控工况下检验真实单电阻逐波 OCP 的覆盖与盲区。参见 [既有 V02-PROT-001](../../../tests/test_cases/V02-PROT-001-cycle-current-limit.md)。
5. **采样与保护分开评价：** 单电阻提供的母线/低侧回流电流，不必在任意时刻等于相电流；六步有效导通窗口和续流路径决定能否用于控制。硬件 OCP 还需独立确保危险电流在要求的时间内得到检测与关断。

## 3. 下一版通用 PCB：三种采样拓扑的装配配置（候选）

**原则：同一套 PCB / 三种固定装配 BOM，不能在功率运行中用小信号跳帽、继电器或普通 0603 0Ω 电阻切换大电流回路。** 仅电阻焊接方式和对应固件配置切换，不代表当前 V5.0 可以直接这样改焊。

计划预留四个电流检测位置：U/V/W 三个低侧 Shunt，另加一个三相公共低侧（DC−）Shunt。各位置需要设计**独立的额定大电流旁路结构**（生产装配二选一：装采样器件或经过验证的功率旁路），不应让开路的 Shunt 焊盘承受功率电流，也不允许同一位置采样器件和旁路并装造成并联短路。

| 装配模式 | U 低侧 | V 低侧 | W 低侧 | 公共 DC− | 控制/保护说明 |
|---|---|---|---|---|---|
| 单电阻（首要目标） | 功率旁路 | 功率旁路 | 功率旁路 | 装 Shunt | 公共电流反馈在有效 PWM 窗口内采样；检验局部母线电容旁路及快速保护 |
| 双电阻（研究模式） | 功率旁路 | 装 Shunt | 装 Shunt | 功率旁路 | 先以 V/W 为候选，对有效时间窗口内两路 ADC 数据重构 U；并非全时刻可观测 |
| 三电阻（研究/对照模式） | 装 Shunt | 装 Shunt | 装 Shunt | 功率旁路 | 三路低侧 ADC / 保护资源检查；三电阻不等于任意时间连续相电流 |

**说明：** 双电阻选择 V/W 是基于现有 OPA1/OPA0 资源记录的首轮候选；最终可以经过原理图与采样窗口评估调整。现有 P5/P6/P7 的 P-X/P-I 跳帽是“相端 MOS 内阻采样信号 / 相 Shunt 采样信号”选择，**不是单/双/三电阻功率回路配置开关**。所有模式都必须审计实际低侧回流、母线电容两侧、驱动器 COM 参考及控制地路径，不能照搬 V5.0 R69/CE2 拓扑。

- **模拟通道：** 首轮候选单电阻 OPA3，双电阻 OPA1+OPA0，三电阻 OPA2+OPA1+OPA0。检查双 ADC 同步采样资源与触发时序；需要 ADC 与 OPA 的板级兼容性审计。
- **硬件保护：** 当前 CMP0 保留给 BEMF，CMP1 一次只能选择一个 OPA/外部输入；三种装配模式都必须单独定义真正可覆盖六扇区危险电流的硬件快速保护方案，不可把“ADC 有三路”当作“三路同时有硬件 OCP”。
- **防错配置：** 板卡丝印明确每种 BOM 的合法组合，提供装配记录、可校验的配置码或上电前人工配置确认；固件固定模式与实际焊接配置一致，出现模式不匹配时禁止 Gate 使能。
- **功率设计约束：** 旁路铜箔、金属连接片、焊盘、过孔的 RMS/峰值电流、热、压降及环路寄生须验收；不可默认使用普通小封装 0Ω 电阻代替 Shunt。单/双/三电阻配置都要重新检查死区、栅极参考与电流返回。
- **基准模式：** 如为比对而同时保留四个 Shunt，须独立定义“测量试验配置”，计算额外的串联压降、地偏移和损耗，**不能把四个全装当作普通三电阻拓扑**。
- **版本策略：** 通用验证板先研究单电阻的有效采样与快速保护，双/三电阻作对照；量产板再根据验证结果去掉不必要的采样通道与配置件。

## 4. 下一版 PCB 设计审查事项（参数待定）

- **Shunt 与母线电容：** 重新布置公共低侧 shunt 和 CE1/CE2 的连接点，使目标的有源导通电流进入采样路径；不能单纯通过拆除 CE2 实现。必须同时比较直流采样准确性与开关回路寄生电感、VDS 尖峰、振铃、EMI、母线纹波。
- **高频去耦：** 保留紧靠功率桥的高频电容及低电感去耦环路；评估电容回流位置是否绕过采样电阻，并量化折中，不能为了采样准确牺牲 MOSFET 开关安全。
- **Kelvin 采样与接地：** 从 shunt 的独立感测端引出差分线路，避开大电流铜皮与开关节点；明确 PGND、GND、驱动器 COM、控制板地、采样参考及外接仪器的安全连接，防止隐蔽并联返回和共模超范围。
- **模拟前端：** 按目标 PWM 频率、有效导通窗口、采样建立时间和允许噪声设计 OPA 增益、偏置、输入 RC、ADC 触发时刻及 CMP 阈值；不预先指定“通用正确”的电阻/电容值。
- **保护完整性：** 明确模拟信号极性、响应延迟、比较器滤波/消隐、Fail 默认态及自动恢复策略。六扇区逐一覆盖，必要时增加独立驱动器 OCP/其他快速保护，不能把 ADC 软件重构当作硬件逐波保护。
- **电源测量：** 将真实主母线 +48V 与 DM_In 辅助供电分开测量或清楚标注，特别是在 P3 可断开时。
- **器件与热设计：** 核算 shunt 峰值/RMS/脉冲功耗、容差、温漂及封装，结合功率回路铜厚、过孔和温升验证。
- **可测试性：** 预留 shunt Kelvin 测点、功率级电流参考测量位置、CMP/Fail 观测点，允许无电机、无主母线进行信号注入和快速保护逻辑验收。
- **版本核对：** 当前 PDF 文件名含 V5.0，所附 PCB 页面图框仍可见 V4.0；投板前核实实际原理图、PCB、Gerber、装配版本一致。

## 5. 变更决策门槛

当前**不**认定必须删除 CE2、必须采用某个固定 RC 数值、或 R69 已能完成逐波限流。待 V0.2 获取 R69 与相电流对照、动态电容回流、OPA3 带宽和 CMP/FAIL 硬件关断证据，并完成三种装配拓扑的功率/保护审查后，才冻结下一版的具体 Shunt/去耦拓扑、旁路结构及元件参数。
