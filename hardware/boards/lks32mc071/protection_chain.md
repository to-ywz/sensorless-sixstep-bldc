## 当前方案优先级（2026-11-08 纠错；优先于文内历史路线 A）

**当前研究方向（保持 CMP0 BEMF + CMP1 OCP 分工，纠正内部 Fail 路由）：**

- **CMP0 保持 PU/PV/PW 三相 BEMF 过零检测，不改 BEMF 模拟输入网络。**
- **CMP1 作为过流比较器，阈值及输入源先在静态实验中验证。**
- **优先验证 CMP1_RAW → MCPWM0_FAIL012.FAIL1 内部通路**：`FAIL1_SEL=1` 选择 CMP1 原始输出，`FAIL1_EN=1` 使能该故障输入，对应 CH0/1/2。该路由已有寄存器/SDK 依据，尚未实测；**不需要预先进行外部飞线**。
- V0.2 先利用现有三相低侧 Shunt + R69 对照研究各扇区采样窗口；**ADC 重构相电流不能代替异步硬件过流保护**。不预先增加飞线。
- **此前“拆 Hall 上拉/电容并把 BEMF 改接 CMP1”的方案已不属于当前计划，应视为已撤销的历史路线，禁止按旧步骤施工。**

**历史飞线备选引脚（当前无需施工）：**

| 资源 | MCU 复用脚 | 48pin LKS32MC071CBT8 封装脚 | 说明 |
|---|---|---:|---|
| CMP1_OUT | P2.5 | 45 | 仅供备用外部回接；与 Hall_V 网络共用 |
| MCPWM_BKIN0 | P2.3 | 43 | 仅供备用外部回接；须先核实跨板连接器 |
| P0.0 | P0.0 | 1 | **不支持 MCPWM_BKIN0，旧版“P2.5→P0.0”错误，禁止接线** |

**先验证内部 FAIL1，不执行飞线。** 若内部通路经实验确认不可用，才评估 P2.5（CMP1_OUT）→P2.3（MCPWM_BKIN0）外部回接；两脚复用、板载网络和电平负载均需先核对。P2.3 不能同时作为 CMP1_OUT 和 BKIN0。P0.0 不支持 BKIN0，旧版 P2.5→P0.0 建议错误。

## 推荐验证顺序（仅最小板级初始化，不先配置全部外设）

0. 先确认安全供电、SWD、时钟、GPIO 默认输出状态和电机/功率级断开；必要时在安全默认状态下保留 Gate 关闭。
1. 单独建立 MCPWM CH0/1/2 安全可观察 PWM（用逻辑波形验证，电机不连接），检查输出互锁、极性和死区。
2. 不飞线，单独配置 CMP1 与 DAC 阈值/限幅模拟输入，先读取 `CMP1_RAW_DATA` 验证输出极性；优先使用内部寄存器/安全观测点，不主动将 P2.5 输出接入功率板 Hall 网络。
3. 功率桥禁能时先通过内部 `FAIL1_SEL=1`、`FAIL1_EN=1` 验证 CMP1 → FAIL1 → CH0/1/2 的逻辑级关断，测试极性、滤波、默认态、延迟及恢复。只有内部路径受阻时才另行评估飞线；不要未经验证启用自动恢复。
4. 完成原始逻辑保护链后再逐个审计 OPA0/1/2/3；区分公共 R69 与相 Shunt 的有效窗口、测量带宽、CMP MUX 可见性和六扇区覆盖，而非仅验证一相电流。
5. CMP0 BEMF 过零检测和开环/闭环电机运行放到保护链可验证之后。

**注意：** 第 2/3 步原则上控制板逻辑级测试、没有电机、没有母线功率输出；禁止使用短接电源或相线的方式触发过流保护。示波器接地须符合板卡隔离与接地拓扑。


## 1. 功率板电流采样硬件

### 三相低侧采样电阻

- U/V/W 低侧各有 0.005Ω/2512 采样电阻：R15（U）、R16（V）、R17（W）。
- 核心板运放输入对应关系：OPA2 接 UP-，OPA1 接 VP-，OPA0 接 WP-。

### P5/P6/P7 电流采样选择

功率板原理图标注：
- P-X：采样 MOS 内阻。
- P-I：采样电阻。

三组 3-pin Header：
| Header | Pin 1 | Pin 2（送 MCU 的采样网） | Pin 3 |
|---|---|---|---|
| P5 | UX | UP | UI |
| P6 | VX | VP | VI |
| P7 | WX | WP | WI |

按图纸连接关系，预期 1-2 选择 P-X（MOS 内阻采样），2-3 选择 P-I（采样电阻采样）。**用户已确认当前实际方案为三电阻采样（P-I：R15/R16/R17），不是 MOS 内阻采样。** 实际 P5/P6/P7 跳帽位置仍建议拍照/断电通断复核，作为硬件配置证据。

### 公共 PGND-GND 采样电阻

- 功率板 R69 = 0.005Ω/2512，标注“采样电阻（合金）”，连接在 PGND 与 GND 之间。
- 核心板 OPA3 输入网络分别通过 R13/R14（1k）连接 PGND/GND，另有 C7 滤波；因此 OPA3 是一条跨 PGND-GND 的差分检测候选通道。
- 它可能反映流经 PGND-GND 连接点的公共回流电流，但是否所有主功率电流都经过 R69，必须结合电源入口、PCB 铜皮/回流路径和实物通断确认，不能仅凭网络名认定为完整母线电流传感器。
- CE1=220μF 负端在 GND，CE2=220μF 与 C25~C27（3×100nF）负端在 PGND；CE2 的局部供电回路可能绕过 R69。这不等于 R69 毫无电流，但不能把 R69 当作任意时刻的相电流真值。
- 核心板 C7=1μF 跨接 OPA3_IP/OPA3_IN；两侧各有 R13/R14=1k 串联。按差分近似，外部 RC 时间常数约 (1k+1k)×1μF=2ms，对应截止频率约 80Hz。该网络明显偏向低频/平均量测，**不能未经验证就用作快速逐 PWM 周期过流保护**。

## 2. MCU 内部 CMP 输入与 MCPWM Fail 映射

### CMP 正端输入选择

按 LKS32MC07x SYS_AFE_REG3 选择表：
- CMP0 正端可选 OPA0_OUT 或 OPA1_OUT（以及 CMP0_IPx 等输入）。
- CMP1 正端可选 OPA2_OUT 或 OPA3_OUT（以及 CMP1_IPx、DAC0 等输入）。
- CMP0 内部 MUX 没有直接选择 OPA2_OUT / OPA3_OUT 的选项。

### MCPWM Fail 通道分配（静态确认；实物未验证）

仓库内 LKS32MC07x 手册转换版 V1.70 表 14-48/49 与 SDK V3.16 `MCPWM_Init()` 交叉核对：
- **时基 0 / CH0、CH1、CH2**：`MCPWM0_FAIL012.FAIL0_SEL=1` 选 CMP0 原始输出；`FAIL1_SEL=1` **选 CMP1 原始输出**。两路均能作为 CH0/1/2 的 Fail 候选源。
- **时基 1 / CH3、CH4、CH5**：`MCPWM0_FAIL345.FAIL2_SEL=1` 选 CMP0；`FAIL3_SEL=1` 选 CMP1。
- 因此旧版“CMP1 只能保护 CH3，无法直接保护 CH0/1/2”的结论**错误**。当前先验证内部 **CMP1 → FAIL1 → CH0/1/2**，不必先将 CMP1_OUT 飞线到 BKIN0。
- Fail 不要求 CPU 中断先执行关 PWM；但来源选择、输入使能、有效极性、滤波、Fail mask、默认电平和 `TR0_AEC` 自动恢复必须分别配置并验证。寄存器可配置不代表已经实现逐波限流。
- 第三方 SDK V3.16 头文件 `lks32mc07x_mcpwm.h` 将 `FAIL1_Signal_Sel` 注释误写为“比较器0或GPIO”，应以寄存器表为准理解为 CMP1/GPIO/CLU 信号选择；暂不直接修改第三方 SDK。

## 3. 对当前三相桥的实际影响

| 电流检测点 | MCU 资源 | 比较器选择候选 | CH0/1/2 硬件 Fail | 当前限制 |
|---|---|---|---|---|
| U 相 R15 | OPA2 | CMP1 选 OPA2_OUT | CMP1 → FAIL1 | 路由存在，尚未验证六扇区有效电流检测 |
| V 相 R16 | OPA1 | CMP0 选 OPA1_OUT | CMP0 → FAIL0 | CMP0 当前负责 BEMF，不能未经重新设计同时作为 OCP |

| 外部 OC | P2.1/CMP1_IP0 | CMP1 外部输入候选 | CMP1 → FAIL1 | 需核实 OC 来源、有效极性、幅度和延迟 |

**仍未解决的问题：**
1. CMP1 的正端 MUX 一次只能选一路；即使三相都有 shunt，也不等于同时监视三相过流。
2. CMP0 当前用于 BEMF，CMP1 选 OPA2 或外部 OC 后，必须证明在每个六步扇区都能于有效 PWM 采样窗口检测危险电流；电流方向、续流路径、比较器开窗和 OPA 饱和均需实测。
3. ADC 的两电阻重构 `iU=-(iV+iW)` 不能替代异步硬件保护；公共 R69 的快速性与电流覆盖范围也未确认。
4. **目前只确认了寄存器和 SDK 层面的硬件路由，不代表逐波 OCP 已实现、实测或放行功率试验。**

## 6. 旧版拆板/飞线路线的撤销结论（不作为工程操作）

曾提出：把 CMP0 改作过流，将 PU/PV/PW 从现有 CMP0 过零输入改接到 CMP1 的 Hall 网络，拆除 Hall 上拉及滤波器件；或从 CMP1_OUT 外接 MCPWM_BKIN0。**这些操作不再是当前板卡方案的必要条件，也不是现行施工/验证步骤。**

纠错依据：此前“CMP1 无法内部关断 CH0/1/2”的判断错误；`MCPWM0_FAIL012.FAIL1_SEL=1` 允许 CMP1 原始输出经 FAIL1 保护 CH0/1/2。因此保持 **CMP0 BEMF + CMP1 OCP** 的现行分工，无须先做 Hall 线路整改或外部飞线。

- **禁止按旧建议使用 P2.5→P0.0**：P0.0 不支持 BKIN0。
- P2.5→P2.3 外部回接仅在内部路径经逻辑实测确认不可用时另行评审，且需重新审计引脚复用、P2 跨板标记冲突、Hall 电路负载；不自动授权施工。
- 旧路线设计推导保留在 Git 历史版本中，用于解释决策变更；当前验证计划只执行前文现行方案。
- 单/双/三电阻兼容板的方案在 [下一版 PCB 设计候选](next_revision.md)，**三种 ADC 测量模式不自动拥有三套并行硬件 OCP**。
