## 高速时序估算（不是已达成的运行指标）

在 1 对极、90,000rpm 下：
- 电气频率：1,500Hz；
- 电气周期：666.7us；
- 六步扇区：111.1us；
- 理想 30° 过零到下一次换相间隔：55.6us；
- 若 PWM=16kHz，每扇区约 1.78 个 PWM 周期。

此数据提醒我们在选定 ADC / CMP、消隐时长、去磁判据和换相定时方式前，先评价可用采样窗口。

## V0.0 电机离线测试

三相全部断开驱动板、电机固定不连接切削附件。

| ID | 试验 | 记录 |
|---|---|---|
| MTR-001 | 四线法测 R_UV、R_VW、R_WU | Ω、环境温度、仪表 |
| MTR-002 | LCR 测 L_UV、L_VW、L_WU | μH、测量频率/电平、转子位置 |
| MTR-003 | 外部低速拖动，开路测线间 BEMF | Hz、线电压真 RMS、峰峰值、波形和旋转方向 |
| MTR-004 | 普通万用表测相线对外壳是否异常导通 | 结果及测试档位 |

在未确认星形或三角形连接前，不将线间电阻直接当作相绕组电阻。

已确认一对极：机械转速 n[rpm] = 60 * fe[Hz]。
线电压 RMS 定义的 Ke = U_LL_RMS / (n/1000)，单位 V/krpm。请在记录中注明测的是线间真 RMS，不与线间峰值、相电压 RMS 的 Ke 混用。

## 首次低能量带电测试前置条件

- 确认两板连接器物理引脚、输入极性和驱动器逻辑。
- 确认 15V、5V 电源和复位默认安全状态。
- 确认电流采样及硬件关断路径，而不是仅有 ADC 读数。
- 电机固定、具备护罩和急停，不安装砂轮片等加工附件。
- 用安全隔离且限流的 DC 电源，在确认的板卡输入电压范围内逐步测试，不能直接以 32V 全功率试机。
