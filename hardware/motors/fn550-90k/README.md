## 4. 简化线间 RL 模型（用于启动风险初估，不是安全限值）

暂采用三个线间读数的均值：
- R_LL,avg = 3.22833 Ω
- L_LL,avg(10kHz) = 360.5333 μH
- 等效时间常数 τ≈L/R≈**111.68 μs**
- 若把 10kHz 小信号电感视为常量，则该频率下线间感抗 2π f L≈**22.65 Ω**

**重要条件：** 以下电流估算假设电阻数据可以近似代表直流线间绕组电阻，10kHz 的 LCR 小信号电感在脉冲过程中近似不变、静止 E=0、两相之间施加完整 32V 直流阶跃。实际 PWM 续流、磁饱和、绕组温升和机械运动均会改变电流。

在该简化假设下：
- 直流极限电流 I∞≈32/3.22833≈**9.91 A**；
- 静止两相通路极限铜耗 P≈32²/3.22833≈**317.2 W**；
- 初始 di/dt≈32/360.5333μH≈**0.0888 A/μs**。

| 完整 32V 电压阶跃时间 | 理论通路电流（非建议脉冲值） |
|---|---:|
| 5 μs | 0.434 A |
| 10 μs | 0.849 A |
| 20 μs | 1.625 A |
| 50 μs | 3.577 A |
| 100 μs | 5.864 A |

公式：I(t) = (V/R) * (1 - exp(-tR/L))。

**绝对不能将上述电流或脉冲时长视为 IPD/ALIGN/逐波限流的设计许可值。** 该计算用于展示在转子不动时电流仍会快速上升，必须先验证功率器件安全范围、热能力、采样和硬件快速关断。

## 5. 对启动与 IPD 的判断

### 首版启动

- 路线暂定 ALIGN -> 受电流约束的分段开环六步加速 -> BEMF 过零验证 -> 无感闭环。
- τ≈112μs 是电流建立的时间尺度，不是换相周期的最佳值。
- 仅有 R 和 L 无法决定转子惯量、负载转矩、开环加速度、可允许启动电流或最低 BEMF 转速。
- 需要优先核实 MCU 内部 OPA/CMP -> MCPWM 硬件保护路径，才允许进行受控功率试验。

### IPD 可行性

- 10kHz 小信号静态线间电感不对称不等于 IPD 的位置辨识度。
- IPD 依赖可重复、与转子角度相关的电感/磁饱和响应；电机可能没有足够可辨识变化。
- 下一步可在固定测试参数下调整转子角度，分别测 L_UV、L_VW、L_WU，并做每个角度的重复测量；尽量记录角度和绕组温度。
- 若电感差异仅体现为固定相间偏差而不随角度变化，则不应直接将最高/最低电感对应某个磁极扇区。
- 真正的脉冲 IPD 仍需单独评估脉冲峰值、比较器阈值、采样时延、重复性和电机转动。

## 6. 高速换相时间参考（非已实现指标）

当 p=1 且 n=90,000rpm：
- 电气频率：1500Hz；
- 电气周期：666.67μs；
- 六步换相扇区：111.11μs；
- 理想过零至下一换相（30° 电角度）：55.56μs；
- 假设 PWM=16kHz：PWM 周期 62.5μs，每扇区约 1.78 个 PWM 周期。

这些值用于评估 ADC/CMP 检测的可用窗口，不代表电机在 32V 下能达到 90,000rpm。
