# Sensorless Six-Step BLDC

**无感 BLDC 六步方波电机控制系统**

面向电动工具的无感 BLDC 六步方波控制系统。首版先基于现有 LKS32MC071CBT8 控制核心板与对应三相功率底板完成硬件验证和算法实现；软件采用分层架构，为后续 MCU / 功率板移植预留边界。

> **项目状态（2026-11-08）：V0.1 逻辑级验证推进中，A0 / A1 / A2 已有用户实测通过记录，A3（三组互补 PWM）用户实测逻辑通过；V0.0 功率级硬件审计及逐波 OCP 仍未完成。**
> 这些结果仅涵盖控制板逻辑输出。六步算法、电机功率运行、CMP/Fail 保护链路尚未通过实物验收。

## 1. 项目目标（Target V1.0）

- 120° 六步方波换相，悬空相 BEMF 过零检测。
- 静止启动：ALIGN + 开环加速；IPD 为可选增强，须先验证目标电机的电感位置特征。
- 旋转启动：识别当前转速与方向，满足条件后同步接管；反向飞车不得盲目强制换相。
- 正转、反转管理；方向切换采用安全减速/停止流程。
- BEMF 过零检测、换相消隐、绕组去磁判断、换相定时。
- 速度闭环（速度估算 + PI + 输出限幅/抗饱和）。
- 保护：逐波过流（cycle）、堵转（stall）、母线欠压/过压（voltage）、过温（temperature）、缺相（phase）、超速（overspeed）、反转（reverse）。
- 首版先在 LKS32MC071CBT8 平台实现；通过 platform / board / motor 分层，为后续移植保留边界。

本项目基础方案为六步方波，不引入 FOC/SVPWM。IPD 使用适合六步桥的脉冲激励和响应判断，不要求实现 SVPWM。

## 3. 开发原则

1. **硬件先行：** 先完成 V0.0 硬件资源审计，再进行功率驱动和算法开发。
2. **分层实现：** MCU 外设访问留在 `platform/`；具体板卡参数留在 `board/`；电机算法放在 `motor/`。
3. **证据驱动：** 每项硬件能力和算法功能都标注状态，并保留波形、日志、测量条件和测试结论。
4. **安全优先：** 硬件快速保护优先于软件控制；首次上电和功率测试必须使用受控低能量工况、限流和适当防护。
5. **不提前泛化：** 第一版只实现当前 LKS32 平台；只定义必要接口，不为尚未验证的 MCU 预建复杂框架。

## 4. 软件分层

```text
Application
    |
Motor Manager / State Machine
    |
    +-- Startup Manager (ALIGN / IPD / Open-loop / Flying Start)
    +-- Commutation & BEMF
    +-- Speed Estimator & Speed PI
    +-- Protection Manager
    |
Board Configuration / Board Support
    |
Platform Driver (LKS32MC071)
    |
MCPWM / ADC / CMP / Timer / GPIO
    |
Gate Driver / Three-phase Power Stage / Motor
```

- `platform/`：芯片外设、寄存器和中断适配。
- `board/`：引脚映射、采样比例、比较器阈值、驱动器使能与板级连接。
- `motor/`：六步换相、启动、BEMF、速度估算、PI、保护策略。
- `application/`：用户命令、参数装载、运行模式和诊断接口。

## 7. 状态标记

- `CONFIRMED`：已由原理图、数据手册或实物确认。
- `INFERRED`：根据现有资料推断，尚未验证。
- `TBD`：待确认。
- `TESTED`：已按记录的测试条件通过验证。
- `FAILED`：测试未通过。
- `BLOCKED`：受硬件、资料或安全条件限制。

**不要把 `TBD` 或 `INFERRED` 写成已实现功能。**
