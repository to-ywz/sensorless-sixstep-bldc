# 未来自动化接口（仅约定）

当前不实现执行器、仪器驱动、脚本或 CI。先用人工流程跑通第一套参考案例，再按实际需要实现 build / flash / capture / report 接口。

| 接口 | 未来输入 | 未来输出 |
|---|---|---|
| build | 固件提交、工具链版本、目标、测试宏/配置 | 产物、校验值、构建日志、退出状态 |
| flash | 板卡标识、构建产物、下载器配置、人工供电确认 | 下载/校验结果、工具日志 |
| capture | 用例 ID、Board Profile 版本、仪器/通道/探头/触发配置、单位和采集条件 | 原始波形/CSV/日志、截图、仪器设置、时间戳 |
| report | 执行 ID、用例版本、板卡/固件版本、实测值、判据及证据引用 | PASS/FAIL/BLOCKED、缺项、不确定性和报告位置 |

共同保留操作者、时间、前置条件、停止原因和错误信息；失败或超时不得继续进入下一危险步骤。接口不得自动跳过接线、首次上电或功率测试的人工安全门禁；判据缺失时返回 BLOCKED，不能猜测 PASS。未来机器格式以成熟人工记录为基础再定，本次不冻结 schema。
