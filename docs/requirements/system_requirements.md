# 系统需求规格

- 文档编号：SYS-REQ
- 基线：Target V1.0
- 状态：规划基线；数值参数待硬件与电机验证

## 1. 系统定位
开发一套面向便携式电动工具的无感 BLDC 六步方波控制系统。首版基于现有 LKS32MC071CBT8 控制核心板和指定三相功率底板实现；软件分层，为后续 MCU / 功率板移植保留边界。

- 控制方式：120° 六步方波换相。
- 位置检测：悬空相反电动势（BEMF）过零检测。
- 启动方式：ALIGN、IPD（可选）、开环加速、飞车启动。
- 运行方式：BEMF 无感闭环换相 + 速度 PI 闭环。
- 方向：正转、反转；识别反拖及反向飞车状态。
- 保护：cycle、stall、voltage、temperature、phase、overspeed、reverse。

基础控制方案不引入 FOC / SVPWM。IPD 使用六步桥臂脉冲激励和电流/电压响应判断，不要求实现 SVPWM。

## 2. 启动系统

| ID | 功能 | 优先级 | 验收摘要 |
|---|---|---|---|
| SYS-START-001 | 静止转子启动 | MUST | 规定电机、母线和负载范围内重复启动 |
| SYS-START-002 | ALIGN 预定位 | MUST | 对齐过程可控，电流不超过安全限制 |
| SYS-START-003 | IPD 初始位置检测 | SHOULD | 证明目标电机存在可辨识的位置相关响应；失败可回退 |
| SYS-START-004 | 开环加速 | MUST | 分段换相频率/周期斜坡可建立转速 |
| SYS-START-005 | 启动限流 | MUST | 启动电流受控，硬件逐波保护有效 |
| SYS-START-006 | BEMF 有效性判断与闭环接管 | MUST | 接管时无持续失步和不可接受电流冲击 |
| SYS-START-007 | 同方向飞车启动 | MUST | 识别转速和方向，满足条件后同步接管 |
| SYS-START-008 | 反向飞车识别 | MUST | 不得盲目强制目标方向换相 |
| SYS-START-009 | 启动失败处理 | MUST | 超时退出、有限重试、故障原因可追踪 |

“任意初始位置启动”必须通过不同转子初始位置的测试定义覆盖范围。静止启动不承诺绝对零反向位移；若产品要求严格禁止反转，需专门验证 IPD 精度和启动策略。

IPD 适用性取决于电机凸极效应、饱和特性、采样分辨率和功率级能力。对无法可靠辨识位置的电机，必须保留 ALIGN 后备方案。

## 3. 换相与 BEMF

| ID | 功能 | 优先级 |
|---|---|---|
| SYS-COMM-001 | 完整六步换相状态表 | MUST |
| SYS-BEMF-001 | 当前悬空相 BEMF 检测 | MUST |
| SYS-BEMF-002 | 相对于虚拟中点/参考电压判断过零 | MUST |
| SYS-BEMF-003 | 过零极性和旋转方向判断 | MUST |
| SYS-BEMF-004 | 换相消隐与绕组去磁分别管理 | MUST |
| SYS-BEMF-005 | PWM 噪声和瞬态滤波 | MUST |
| SYS-COMM-002 | 过零后约 30° 电角度换相 | MUST |
| SYS-COMM-003 | 高速换相提前角优化接口 | SHOULD |

换相消隐时间与绕组去磁时间不是同一概念，必须分别设计和验证，不能用单一固定延时替代所有干扰处理。

## 4. 运行控制
- 运行控制以速度闭环为主。
- 根据有效 BEMF 过零/换相时间计算电角速度和机械转速。
- 速度 PI 调节 PWM 占空比。
- 支持速度给定斜坡、加速、减速和负载突变。
- PI 输出具有占空比限幅、积分限幅和抗饱和。
- 电流限制和硬件保护优先级高于速度 PI。
- 首版不要求独立转矩控制模式，也不要求完整电流闭环；电流采样首先用于启动限流、保护和诊断。
- 稳态速度误差目标暂定为规定工况下 ±5%；最终适用转速区间和动态指标待实测后冻结。

## 5. 正反转与反拖
1. 用户主动切换方向：先降低目标转速，安全停止后再按新方向启动。
2. 电机被外部负载反拖：检测实际转向和转速，根据状态选择同步接管、等待或安全停机。
3. 非预期反转：检测换相顺序与目标方向不一致，禁止继续盲目驱动。
4. 不允许电机高速运行时直接反转六步换相表。
5. 主动再生制动暂不纳入首版承诺；必须先验证母线能量吸收能力和过压保护。

## 6. 保护功能

| ID | 保护 | 触发依据 | 处理方式 |
|---|---|---|---|
| PROT-CYCLE-001 | 逐波过流 | 硬件比较器/驱动器 OCP | 硬件快速关断 PWM 或 Gate Driver |
| PROT-STALL-001 | 堵转 | 电流异常、转速无法建立、BEMF 丢失 | 停机、延时及有限重试 |
| PROT-VOLT-001 | 欠压/过压 | VBUS 低于/高于阈值 | 降额或停机；过压时考虑母线能量 |
| PROT-TEMP-001 | 过温 | NTC 或驱动器温度输入 | 降额或停机 |
| PROT-PHASE-001 | 缺相 | BEMF/相电压响应异常 | 停机并记录故障 |
| PROT-SPEED-001 | 超速 | 实际转速超过上限 | 限制输出或停机 |
| PROT-REV-001 | 反转 | 实际方向与允许方向不一致 | 拒绝接管或停机 |

逐波限流必须由硬件快速保护链路实现。软件负责故障统计、锁存和恢复管理，不能用普通 ADC 中断替代硬件快速关断。

## 7. 非功能需求
- 硬件保护不依赖主循环及时响应。
- 中断执行时间有上限，不得在高优先级 ISR 中阻塞。
- 算法模块不直接访问 MCU 寄存器。
- 参数必须标注单位、范围、默认值来源和验证状态。
- 故障状态可追踪，恢复条件明确。
- 测试结果可复现，结论必须有测量或日志证据。

## 8. 暂不冻结的数值参数
母线范围、PWM 频率、死区、电流阈值、采样增益、最低可靠 BEMF 转速、ALIGN 时间、IPD 脉冲参数、开环初始频率与加速度、消隐时间、去磁判据、速度 PI 参数及各保护阈值均为 TBD。

所有数值必须来自当前板卡原理图、器件手册、实测或明确的设计计算，不得将历史讨论中的示例值直接写成硬件基线。
