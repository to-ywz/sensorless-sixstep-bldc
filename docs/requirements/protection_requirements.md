# 保护需求规格

## 1. 保护优先级
1. 硬件逐波过流关断：最高优先级，不等待软件。
2. 硬件驱动器故障/互锁：直接进入安全输出状态。
3. 软件快速故障：欠压、过压、超速、反转、缺相、堵转。
4. 热管理：根据温度传感器能力执行降额或停机。
5. 故障管理：记录、锁存、恢复许可和有限重试。

## 2. 故障处理原则
- 默认安全态：功率 PWM 禁止，Driver Enable 进入经硬件确认的安全电平。
- 逐波过流的自动恢复/锁存方式必须由功率级和器件安全要求决定。
- 堵转恢复必须限制重试次数，并设置冷却/等待时间。
- 欠压恢复需有滞回，避免临界点反复启停。
- 过压故障需评估电机回馈能量和母线吸收路径。
- 过温可先降额；超过停机阈值则锁存或等待充分冷却。
- 缺相、BEMF 长时间丢失和方向异常默认按严重故障处理。
- 清除故障前必须确认故障源已消失，不能仅清 MCU 标志位。

## 3. 逐波过流的硬件链路
目标链路：

Current Sense -> Amplifier / Filter -> Comparator or Driver OCP -> PWM Break / Driver Disable -> Gate outputs safe -> MCU captures fault.

以上仅是目标结构。必须通过原理图追踪和受控测试确认实际连接、响应时间、故障覆盖范围、锁存行为和默认态。

## 4. 故障记录字段
记录故障码、状态机状态、方向、目标速度、估算速度、母线电压、电流采样、当前扇区、最近 BEMF 时间戳、故障时间和恢复计数。
