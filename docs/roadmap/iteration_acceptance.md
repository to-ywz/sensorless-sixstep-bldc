所有数值阈值和时间参数应在硬件审计及电机实测后冻结。未通过前一阶段安全门槛，不进入下一阶段功率测试。

## V0.0 — 硬件资源审计
任务：
- 确认 MCU 完整型号、封装、核心板和功率板版本。
- 确认六路 PWM 引脚、极性、互补关系、死区和同步更新能力。
- 确认驱动器 Enable / Fault 逻辑。
- 确认 CMP 输入、阈值、极性、滤波及输出路径。
- 确认硬件故障能否直接关断 PWM 或 Gate Driver。
- 确认三相 BEMF 分压、保护、ADC/CMP 通道和虚拟中点参考。
- 确认电流采样拓扑、采样电阻、放大倍数、偏置和采样时序。
- 确认母线电压分压与允许范围。
- 确认温度输入是否存在。
- 确认电机相序、极对数和额定参数。
- 确认测试电源、限流值、保险、急停和放电方式。

验收：
1. 形成完整硬件资源映射表。
2. 每个采样量都有物理量转换关系和标定计划。
3. 明确逐波过流是否能由硬件实现。
4. 明确哪些功能受限于现有硬件，哪些需要改板。
5. 每项结论有原理图页码、手册章节或实测证据。

交付物：硬件资源表、采样标定表、保护链路图、硬件风险清单。

## V0.1 — 六步基础驱动
实现六步换相表、PWM 占空比控制、互补输出/死区配置、安全停机、同步更新和硬件故障关断。验收六种导通状态正确、正反向序列正确、无上下桥臂直通、无异常窄脉冲、故障时功率输出可靠关闭。

## V0.2 — 采样与逐波保护
完成电流零点/比例、VBUS 和相电压标定；完成 ADC 与 PWM 同步；确认比较器阈值、极性和硬件关断路径。ADC 与外部仪表误差满足设计指标；电流采样无明显换相瞬态误触发；示波器验证逐波关断。

## V0.3 — 静止开环启动
实现 ALIGN、六步开环换相、线性/分段频率斜坡、启动限流、超时和失败处理。空载和规定轻载可靠启动；不同初始转子位置进行覆盖测试；启动电流不超过限制；失步/堵转能退出。每种测试工况建议至少连续完成 20 次启动；该次数是开发验证建议，不是量产可靠性指标。

## V0.4 — BEMF 过零检测
实现六扇区悬空相选择、虚拟中点比较、过零方向、blanking、demagnetization、滤波和时间戳。六个扇区的相选择与极性正确；振铃不造成错误过零；确定最低可靠检测转速；ADC/CMP 结果与示波器一致。

## V0.5 — 无感闭环换相
实现连续过零有效性验证、过零周期测量、约 30° 电角度换相延时、开闭环相位同步和失步处理。能从静止启动进入闭环；接管无明显电流冲击；不持续失步；建议至少完成 20 次重复接管测试。

## V0.6 — 速度闭环
实现 BEMF 转速计算、速度 PI、占空比限幅、速度给定斜坡、anti-windup、电流限制协调、负载突变和卸载过冲抑制。规定区间内稳态速度误差先以 ±5% 为目标；阶跃响应、负载恢复和突然卸载均无不可接受超调或飞车。

## V0.7 — 高级启动与方向管理
实现 IPD 脉冲检测及置信度、飞车启动、方向/速度识别、反拖处理、自适应开环加速、有限重试。静止启动策略可用；同方向飞车可同步接管；反向旋转不盲目换相；主动方向切换经过安全减速；IPD 不适用时回退 ALIGN。

## V0.8 — 完整保护系统
逐项对 cycle、stall、voltage、temperature、phase、overspeed、reverse 进行模拟或受控注入测试。验证触发条件、PWM 动作、故障码、锁存/恢复、有限重试和重复性。禁止通过直接短接母线或超额定操作制造故障。

## V1.0 — 工程化版本
1. 静止启动、飞车启动、正反转及反拖处理完整。
2. BEMF 无感闭环换相稳定。
3. 速度闭环满足冻结后的指标。
4. 逐波过流保护可靠。
5. 全部指定保护通过故障注入测试。
6. PWM 无异常脉冲。
7. 完成连续运行和重复启停测试。
8. 参数配置与硬件驱动分离。
9. 算法层不依赖 MCU 专用寄存器。
10. 提供完整测试记录、参数说明和故障诊断信息。

V1.0 首先证明 LKS32MC071 平台实现。跨 MCU 移植能力须通过第二个平台实际移植验证，不提前宣称完成。

## 测试数据与记录
每次测试记录硬件版本、电机参数、母线电压、负载、软件版本、关键参数、测试结果、示波器波形或日志。

建议采集六路 PWM/Gate 波形、三相端电压及参考电压、电流采样和外部电流测量、VBUS、换相时间戳、BEMF 过零时间戳、目标/实际速度、故障码和状态机记录。

不接受仅以“电机转起来了”作为验收标准。
