# 六步换相策略

## 1. 基本原则
采用 120° 六步方波控制。每个扇区两相导通，一相悬空用于 BEMF 检测。具体高低桥臂状态、PWM 所在桥臂、续流路径和正反转序列必须依据实际驱动器与板卡验证后冻结。

## 2. 换相控制职责
- 维护当前电角扇区。
- 根据方向选择下一扇区。
- 将扇区映射到桥臂开关状态。
- 在安全时刻更新 PWM 输出。
- 处理换相前后的消隐和采样窗口。
- 记录换相时间戳，供速度估算使用。

## 3. 安全要求
- 禁止上下桥臂直通。
- 死区由硬件 PWM 单元优先实现并实测确认。
- 扇区更新应同步，避免半周期内出现不完整状态。
- 故障触发时立即进入安全输出态。
- 不允许在高速运行时直接反转换相表。

## 4. 方向与相序
相序、相电压极性和电机接线关系必须以实际波形验证。不能仅依据软件数组下标推断物理正转方向。
