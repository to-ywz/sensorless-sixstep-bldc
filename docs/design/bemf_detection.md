# BEMF 过零检测设计

## 1. 检测对象
在每个六步扇区中，检测当前悬空相反电动势相对于虚拟中点或等效参考电压的过零事件。虚拟中点的实际实现、分压网络、保护和 MCU 通道必须由硬件审计确认。

## 2. 处理链
1. 根据当前扇区选择悬空相。
2. 确认 PWM 开关状态和有效采样窗口。
3. 换相后进入 blanking，屏蔽开关瞬态与振铃。
4. 判断绕组续流/去磁是否结束；去磁判断独立于 blanking。
5. 对有效采样值进行极性判断、迟滞/数字滤波。
6. 检查过零顺序、时间连续性和速度合理性。
7. 生成带时间戳的有效 ZC 事件。

## 3. Blanking 与 Demagnetization
- Blanking：换相后暂时忽略检测输入，避免开关振铃造成误触发。
- Demagnetization：等待上一导通状态的绕组电流衰减，避免续流电压被误判为 BEMF。
- 两者物理原因不同，时间可能随转速、电流、占空比和电机参数变化。
- 初期可采用保守固定窗口做验证，再根据测量优化；不能将其等同为同一个固定延时。

## 4. 换相定时
典型六步中，BEMF 过零位于当前 60° 电角扇区中点附近，理想情况下过零后约 30° 电角度进行下一次换相。实际相位偏差受滤波、采样、绕组参数、开关时序和转速影响，应通过波形验证和参数优化。

## 5. 失效处理
连续漏检、错误极性、事件时间间隔异常或扇区序列不匹配时，标记 BEMF invalid。运行中失效应进入受控降额/停机策略，不能继续无限外推换相。
