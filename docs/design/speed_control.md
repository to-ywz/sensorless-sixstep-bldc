# 速度估算与速度 PI

## 1. 速度估算
依据有效 BEMF 过零事件或换相事件间隔计算电角速度，再结合电机极对数换算机械转速。极对数、方向和相序必须来自电机参数配置并经实测确认。

## 2. 速度 PI
速度误差 = 目标速度 - 实际速度。PI 输出作为 PWM 占空比/电压请求，经过以下约束：
- 最小/最大占空比限制；
- 启动与运行状态限制；
- 电流限制；
- 母线电压和温度降额；
- 积分限幅及 anti-windup。

## 3. 动态要求
验证速度阶跃、负载增加、负载突然卸除、低速运行和速度指令变化。重点观察速度过冲、恢复时间、电流峰值和失步风险。

## 4. 首版边界
首版以速度闭环为运行控制，不承诺独立转矩闭环。电流采样用于限流、保护、诊断及必要的 PI 输出约束。
