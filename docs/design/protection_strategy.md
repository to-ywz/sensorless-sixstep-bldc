# 保护策略

## 1. 硬件快速保护
逐波过流必须通过比较器或驱动器 OCP 等硬件链路关断 PWM / Gate Driver。软件只负责记录、统计、锁存和恢复策略。必须实测关断延迟和故障覆盖范围。

## 2. 软件保护
- Stall：启动超时、BEMF 丢失、转速长期低于阈值且电流异常。
- Voltage：母线欠压/过压，带滞回和滤波。
- Temperature：按温度区间降额，超温停机。
- Phase：相电压/BEMF 响应异常、持续缺相。
- Overspeed：实际速度超过硬件和电机允许值。
- Reverse：实际方向与允许方向不符。

## 3. 恢复策略
每类故障定义严重等级、是否锁存、恢复条件、冷却时间、最大重试次数和故障码。不可恢复故障必须人工复位或重新上电；不能默认自动重启。
