# 启动策略设计

## 1. 静止启动路径
首版基线：PRECHECK -> ALIGN -> OPEN_LOOP_ACCEL -> BEMF_VALIDATION -> CLOSED_LOOP_RUN。

### ALIGN
向选定的固定六步矢量施加受限电压/占空比，使转子趋向已知扇区。必须限制电流、持续时间和占空比。ALIGN 可能引起转子移动，不能承诺零反向位移。

### IPD（可选增强）
通过一组受控桥臂脉冲激励，观察电流斜率、峰值或电压响应差异，推断初始转子扇区。是否可行取决于电机凸极性/饱和特征、脉冲能量、采样分辨率和功率级带宽。先做电机适配性实验，不把 IPD 当作所有电机必然有效的算法。

IPD 属于六步桥脉冲检测，不需要 SVPWM。若识别置信度不足，应回退 ALIGN，而不是输出不确定的扇区。

### 开环加速
以换相周期为控制量，按分段斜坡逐步提高电角频率。可采用分段线性 ramp、限加速度曲线或查表曲线；每个区间受电流和母线能力约束。初期先使用可解释、可调参的分段线性 ramp，不急于引入复杂自适应算法。

### 闭环接管
要求连续多个过零事件满足：
- 顺序与预期扇区一致；
- 极性正确；
- 过零周期变化合理；
- 估算速度达到最低可靠检测范围；
- 开环预测换相时刻与 BEMF 相位误差在允许窗口内。

接管时应保持换相相位连续，避免占空比和换相周期突变。

## 2. 飞车启动
先检测 BEMF 是否存在，再判断旋转方向和速度。只有同方向且估算可信、速度处于可接管区间时才同步接管。反方向旋转时禁止直接按目标方向驱动；可等待自然停转或执行经验证的安全处理。

## 3. 启动失败
BEMF 不成立、过流、超时、转速未建立或方向异常时，撤销驱动并记录原因。重试必须有次数上限、等待时间和热保护约束。
