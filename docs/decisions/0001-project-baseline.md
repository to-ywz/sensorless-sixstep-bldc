# ADR-0001：项目基线与首版平台

- Status: Accepted
- Date: 2026-11-04

## Context
目标为面向便携式电动工具的无感 BLDC 六步方波控制系统。先完成现有硬件平台的可验证实现，同时为未来移植保留软件分层。

## Decision
- 基础控制采用 120° 六步方波，不采用 FOC/SVPWM 作为本项目基础方案。
- 位置检测采用悬空相 BEMF 过零。
- 运行控制采用速度闭环。
- 首版以 LKS32MC071CBT8 和当前指定功率板为目标平台。
- ALIGN + 开环加速作为静止启动基线；IPD 为可选增强，必须先验证电机适用性。
- 飞车启动、方向识别和反拖处理属于目标版本能力。
- 逐波过流必须由硬件链路实现。
- Platform / Board / Motor Algorithm 分层；暂不建设未经验证的多 MCU 抽象框架。

## Consequences
- V0.0 必须先审计硬件资源和保护路径。
- 所有未核实的电气参数保持 TBD。
- 跨 MCU 兼容性需通过第二平台移植验证。
