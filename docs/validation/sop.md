# 硬件生命周期 SOP

本文件定义流程骨架；具体接线、数值和操作以已核实 Board Profile 及对应测试用例为准。未填写的安全阈值或测点不得靠示例值补齐。

| 阶段 | 检查范围 | 放行依据 |
|---|---|---|
| P0 设计与打样准备 | 原理图、电源/采样/保护路径、PCB 布局、BOM/封装/极性、调试接口与测试点；打样及焊接装配核对 | 设计版本、评审问题、装配差异可追溯，阻断项关闭 |
| P1 焊接后无电检查 | 外观、错件/反向/虚焊/连锡、各电源轨对地阻值、短路、MOSFET/二极管、接插件及关键网络连通性 | 记录测点、阻值和判断依据；异常解决后才接电 |
| P2 首次上电与基础功能验证 | 分电源域限流上电，电压/静态电流/温升；A0 MCU/时钟/GPIO，A1 单路 PWM，A2 互补/死区，A3 三相六路，A4 六步逻辑，A5 预驱/Gate | 按现有 A0～A5 用例逐级执行，记录默认态、停止及复位行为；保留所有量化遗留项 |
| P3 采样与保护验证 | 电流/母线/BEMF/温度采样标定，CMP→PWM 硬件关断，欠压/过压/过温、恢复条件与覆盖范围 | 实测误差、阈值、响应时间、关断及恢复符合板级判据 |
| P4 电机运行验证 | 定位启动、开环加速、过零检测、闭环、方向管理、负载与热、堵转及故障恢复 | 在已验证保护与明确工况下完成对应运行验收 |

## 每次执行与门禁

1. 锁定板卡/装配版本、固件提交和用例版本；确认仪器、探头参考点、接线、母线/电机状态和限流值。
2. 按阶段前置条件执行；首次供电和功率级操作前由人工确认接线、隔离、能量边界及紧急断电方式。既有 A5 的隔离供电条件继续按原用例执行。
3. 逐项记录实测值及原始证据位置：PASS 表示符合明确判据；FAIL 表示不符合；BLOCKED 表示前置条件不满足。未执行保留 NOT RUN，不计为通过。
4. FAIL 时停止相关后续测试，关断输出、断电并确认储能释放后排查；关联故障记录，整改后重跑失败项和受影响回归。BLOCKED 补齐条件后再执行。
5. 阶段放行需核对必测项与证据，列明缺项及适用范围；P2 通过不能代替 P3/P4，不能自动授权电机功率运行。
