# 硬件研发与验证体系

这是长期工程能力建设：将个人经验沉淀为可重复执行、可培训新人、可交接给 AI 的规范。当前 LKS32MC071 BLDC 板作为第一套参考实现；通用方法、MCU 外设适配与板级参数分开维护，不能把当前板参数套用于任意硬件。

## 阶段与版本

P0～P4 表示硬件生命周期；V0.0～V1.0 仍按[现有路线图](../roadmap/iteration_acceptance.md)推进。两者不是一一对应。A0～A5 是 P2 内部的递进验证，不是整个硬件生命周期，也不代表采样、保护及电机运行已验收。现有用例和报告中的进度、条件及未完成项继续有效，本说明不追认任何阶段通过。

每次执行关联用例 ID、板卡版本、固件提交、配置与证据。用例保存方法和判据，报告保存本次条件、实测值和结论；故障案例链接失败报告、修复及回归证据，避免复制多份事实。
