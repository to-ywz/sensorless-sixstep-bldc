# 总体验证计划

## 1. 目的
定义从 V0.0 到 V1.0 的验证层级、证据和放行条件。

## 2. 进入条件
- 已确认板卡和 MCU 版本。
- 已确认测试电源和限流方式。
- 已检查急停、保险、放电和防护。
- 已确认硬件过流关断路径。
- 测试人员了解探头接地和高压测量风险。

## 3. 测试阶段

| 阶段 | 主要测试 | 放行条件 |
|---|---|---|
| V0.0 | 硬件审计 | 关键网络和安全链路有证据 |
| V0.1 | PWM / 六步 | 无直通、输出安全、时序正确 |
| V0.2 | ADC / CMP | 标定完成、逐波硬件关断通过 |
| V0.3 | 开环启动 | 受控工况重复启动 |
| V0.4 | BEMF | 六扇区检测、消隐/去磁有效 |
| V0.5 | 闭环换相 | 开环接管稳定 |
| V0.6 | 速度闭环 | 稳态与动态指标通过 |
| V0.7 | 高级启动 | IPD/飞车/反拖适用工况通过 |
| V0.8 | 故障注入 | 每类故障动作和恢复策略通过 |
| V1.0 | 系统验证 | 长时间运行和完整回归通过 |

## 4. 测试记录要求
所有报告使用 reports/test_report_template.md。图片、CSV 和日志必须有文件名、单位和测量条件。未通过项目创建 Issue 并记录复现步骤。
