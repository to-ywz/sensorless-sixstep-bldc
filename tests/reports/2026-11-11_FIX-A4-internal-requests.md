## 现场对照（用户实测，无附图项不编造读数）

| CH0低字节 | 27/UP | 28/UN |
|---|---|---|
| 0x1C | 低 | 高，无PWM |
| 0x2C | 高 | 低，无PWM |
| 0x14 | 高 | PWM，异常 |
| 0x18 | 低 | PWM |
| 0x04 | 高 | 低，无PWM，异常 |
| 0x05 | PWM约24% | 高 |

IO01高字节在对照中保持0x1C。A3对照反馈UN约26%、UP约24%；预驱供电后用户报告上管约24%、下管约76%，未将占空比合计约100%作为死区/无重叠验收。

0x1C/0x2C支持静态电平到27/28脚对应正确；不能因此交换P/N引脚。0x05的恢复直接证明N极性配置与此次混合输出行为有关。手册 `13_MCPWM.md` 中心模式IO冲突保护说明（约214～218行）提示：软件输出也保留内部短路保护。因此本修复将内部导通请求与物理驱动极性分离，避免以内部N=1表示低侧关断。仅凭这些外部波形尚不能重建所有异常组合的内部状态机，不声称已完整解释0x04等组合的硅实现。

## 上次修复的不足及本次修改

2026-11-09第一次A4修复直接用软件N高实现LIN高，但N极性未反相；原宿主测试只检查了最终物理电平，没有约束极性转换前内部请求，因而未捕获此问题。该修复不能视为A4功能已修复通过。

本次保持MCPWM内部正逻辑：P/N均0为关断、高侧PWM时N固定0、低侧导通时P=0/N=1；普通输出的N极性位开启，将N请求转换为LKS560物理LIN。GPIO关断和CH_DEF仍是物理P低/N高，CH_DEF绕过普通极性，不再次反相。

| 角色 | 内部P/N | N反相后物理P/N | 通道字节 |
|---|---|---|---|
| 关闭 | 0/0 | 0/1 | 0x0D |
| 高侧PWM | PWM/0 | PWM/1 | 0x05 |
| 低侧开启 | 0/1 | 0/0 | 0x1D |

| 扇区 | IO01 | IO23低字节 |
|---|---|---|
| S0 | 0x1D05 | 0x0D |
| S1 | 0x0D05 | 0x1D |
| S2 | 0x050D | 0x1D |
| S3 | 0x051D | 0x0D |
| S4 | 0x0D1D | 0x05 |
| S5 | 0x1D0D | 0x05 |

STOP可以保留前一扇区IO寄存器内容，由MOE=0及GPIO回退命令P低/N高关断，不能要求STOP后的IO01必须等于某个关闭字。
