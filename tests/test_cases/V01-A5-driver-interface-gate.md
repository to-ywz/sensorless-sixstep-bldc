## 1. 为什么做这一步

A4确认的是MCU控制逻辑，不能证明驱动器能正确识别输入或MOS实际关断。A5沿链路分段验证：MCU引脚→HIN/LIN→驱动输出→MOS实际Gate/Source。每段用自己的本地参考点，不能把逻辑PWM、HO对地波形、实际VGS混为一谈。

## 3. A5-0：先完成断电与资料核对

| 核对项 | 要得到的事实 | 影响 |
|---|---|---|
| 实物版本/芯片丝印 | 底板版本、U1/U2/U5实际型号和封装 | 确定适用手册及针脚 |
| 逻辑与驱动供电 | MCU供电、驱动VCC入口、稳压路径、是否依赖BUS、反灌路径 | 决定能否仅驱动电源供电，不能假定需要或只需两台电源 |
| 输入兼容性 | HIN/LIN阈值、工作/绝对最大范围、断电输入约束、串联器件 | 评估既有约5V信号及HW-001负向过冲 |
| 默认关断 | 是否存在独立EN/SD/Fault、实际网络及默认上下拉 | 不假设芯片有独立使能脚，也不把STOP当硬件急停 |
| 地与参考点 | MCU GND、驱动COM、低侧Source、PGND/GND/R69实际连接 | 防止地夹短接采样电阻或其它网络 |
| Gate路径 | LO/HO至MOS栅极的电阻/缓冲、MOS Source、下拉 | 分清驱动输出与实际VGS |
| 高侧自举 | VB/VS或等效脚、充电路径、所需开关状态及限制 | 决定断母线条件下能否验证高侧 |
| 仪器 | 探头倍率、额定值、通道共地、差分探头是否具备 | 确定测量可执行性 |

A5-0资料齐备后，填写可执行的供电电压、限流值、接线图和量化阈值，再做带电测试；现文档不是可直接照接的供电指令。

## 4. A5-1：输入链路，先不主动开启Gate

目标：六路在驱动器HIN/LIN端与MCU侧一一对应，电平满足手册要求，STOP/复位保持要求的无效态。

- 断电先核对六条信号路径及本地COM参考。驱动未供电时，须先确认输入允许被驱动，否则停在断电核对，不用MCU PWM试探断电输入。
- 输入允许条件成立后，使用A4手动静态模式及STOP分组测MCU侧和对应HIN/LIN侧。不重新跑全部A4，只核对传输后的相序、极性和默认态。
- 短弹簧地测正/负峰值，关联HW-001。若峰值超手册范围，记录并暂停进入驱动供电测试，先核实测量回路和信号完整性，不盲目加RC。
- 仪器显示STOP仅代表采集停止，固件STOP须独立操作和记录。

通过：六路映射/逻辑正确、输入高低电平与峰值满足对应手册条件；每项注明实际数值和来源。单纯能看到波形不算电气兼容通过。

## 5. A5-2：仅驱动供电下的低侧验证

前置：A5-0/1通过，驱动VCC接法和范围确认，主母线断开并确认无反灌；上电前固件STOP，电机断开。

| 测试 | 观测目标 | 原因/判断 |
|---|---|---|
| 只供电、不START | 驱动VCC及实际低侧Gate-Source电压 | 确认上电不误导通；阈值来自驱动及MOS手册 |
| 单扇区静态 | 对应LIN与低侧VGS | 判断输入→驱动→MOS Gate是否同极性，确认下拉及幅度 |
| U/V/W分别验证 | 三相低侧常高、低及STOP回低 | 不由一相正常推断全部正常 |
| STOP/复位 | VGS回到关断范围、无异常保持或再次启动 | 验证MCU物理P低/N高能否落实为栅极关断 |

两探头即可分组。普通示波器通道地通常共地，不能把两根地夹分别夹在不同Source/COM网上跨接采样电阻。低侧Source未被确认与示波器保护地等电位前，不直接夹地；差分测量或其它接法须按仪器规格及接地拓扑确定。

## 6. A5-3：高侧另行审查后执行

高侧必须观察HO相对VS、实际Gate相对Source；HO对逻辑地不等于VGS。母线断开时自举可能无法充电，高侧无输出不能立即判芯片故障。也不为让波形出现而接母线、短接相点或强行给自举电容供电。

待明确自举充电方案、隔离/差分测量能力及所有参考点后，另附高侧测试接线图。可执行则验证三相高侧VGS、关断、相应H/L非重叠；条件不足则高侧项目明确保留待测，不能将A5整体判通过。
