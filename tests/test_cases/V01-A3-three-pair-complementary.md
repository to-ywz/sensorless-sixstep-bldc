# V0.1-A3 — CH0/CH1/CH2 三组互补 PWM 逻辑验证

- **Status: PASS — USER-REPORTED LOGIC BENCH / REPRESENTATIVE PHOTOS ARCHIVED**
- **Milestone:** V0.1
- **Predecessor:** V0.1-A2（单组 CH0P/CH0N 互补输出，用户确认逻辑功能通过）
- **Scope:** MCU 六路 PWM 引脚的三组互补输出验证。
- **Out of scope:** 六步换相状态表、栅极驱动输出、功率桥开关、电机运行和保护链路验收。

## 1. 目标

把 A2 已验证的单组 CH0P/CH0N 扩展到 CH0、CH1、CH2 三组互补输出，确认：
- 六个 MCU 引脚映射正确。
- 三组输出频率、极性、占空比和死区配置一致。
- 每组 P/N 不发生逻辑高电平重叠。
- 启动、停止和复位安全状态正确。

本阶段仍然是逻辑级验证，不代表六步功率驱动已经通过。

## 2. 引脚映射

| 相 | MCPWM | P 输出 | N 输出 | 核心板信号 |
|---|---|---|---|---|
| U | CH0 | CH0P / P1.4 | CH0N / P1.5 | UP / UN |
| V | CH1 | CH1P / P1.6 | CH1N / P1.7 | VP / VN |
| W | CH2 | CH2P / P1.8 | CH2N / P1.9 | WP / WN |

映射依据：`hardware/boards/lks32mc071/pin_mapping.md`。实测前仍应确认板卡版本与连接器方向。

## 3. 安全条件

- 逆变器直流母线物理断开并确认储能电容放电。
- FN550-90K 与三相电机线断开。
- 首轮只在 MCU 引脚测量，探头地接已确认的 MCU 逻辑 GND。
- 不将示波器地夹接到半桥开关节点、BUS− 或不确定的功率参考点。
- 本测试不要求开启功率输出；不得因六路逻辑 PWM 正常就给功率桥上电。
- HW-001 仍为轻量记录。进入驱动器输入/栅极波形或功率级测试前，先核对相关输入绝对最大额定值。

## 4. 初始配置建议

沿用 A2 的逻辑级测试参数，仅用于三组输出一致性验证：

| 项目 | 初值 |
|---|---:|
| MCPWM 时钟 | 与 A2 相同 |
| CLK_DIV | 0 |
| TH0 | 2400 |
| CH0 比较值 | TH00=-600，TH01=+600 |
| CH1 比较值 | TH10=-600，TH11=+600 |
| CH2 比较值 | TH20=-600，TH21=+600 |
| CH0/1/2 模式 | 中心对齐 |
| IO0_PPE / IO1_PPE / IO2_PPE | 全部 DISABLE |
| CH0/1/2 的 P/N 输出来源 | 均选择 MCPWM 硬件输出 |
| DeadTimeCH012N/P | 48 / 48 counts（沿用 A2，约 1µs） |
| 六路默认输出 | LOW |

说明：
- CH0、CH1、CH2 的死区寄存器在当前 SDK 结构体中共用 `DeadTimeCH012N/P`。
- 三组通道的比较值必须分别配置；不能只设置 CH0 的 TH00/TH01。
- 48 counts 只是本次逻辑级验证值，不是最终功率级死区定值。
- 本阶段不使用推挽周期交替功能（IOx_PPE）。

## 5. 构建与测试步骤

已实现独立模块 `firmware/tests/bench/test_mcpwm_three_pair.c/.h`，接入 Keil 主目标 `Linko 07x Project`。

- 在 C/C++ 的 Define 中仅添加 `BENCH_TEST_MCPWM_THREE_PAIR`，移除 A1/A2 的测试宏。
- 不定义测试宏时仍运行 A0；同时定义多个测试宏会触发编译错误。
- 执行 Rebuild，保存完整 Build Output，确认零错误后再烧录。不要使用 `_ac6` 目标。
- START1（P2.11）消抖后启动；STOP1（P2.12）优先停机。上电按住 START 不自动启动，须释放后重新按下。
- STOP 先清除输出使能，再将 P1.4～P1.9 恢复 GPIO 低电平；STOP 是软件轮询控制，不是硬件急停。
- 本模块未启用或验证 CMP/Fail 过流保护输入；六路 FAIL mask 使能仅用于确保 MOE 清零时选择低电平默认值。


1. 创建独立 A3 bench test 配置，不覆盖 A2；构建前确认只启用一个 bench-test 宏。
2. 上电默认状态下检查 P1.4～P1.9 六路均为稳定低电平。
3. 启动后先测 CH0P/CH0N，确认频率、占空比和两方向死区。
4. 再测 CH1P/CH1N、CH2P/CH2N，分别记录相同指标。
5. 至少选取一组跨通道测量，确认 CH0/1/2 周期一致、更新同步；如有偏差，记录实际相位差，不先假定是硬件故障。
6. 按 STOP，确认六路均进入低电平安全态。
7. 复位/重新上电，确认六路不会出现非预期高脉冲。
8. 重复启动/停止，检查是否出现窄脉冲或通道残留输出。

示波器通道有限时可分组测量，不要求一次捕获六路；每次记录测点、参考地、探头倍率、带宽限制和时基。

## 6. 验收标准

- [x] 上电默认 P1.4～P1.9 均为低。
- [x] CH0、CH1、CH2 三组 P/N 频率均约 10.1kHz。
- [x] 三组 P/N 极性与映射正确。
- [x] 每组 P/N 正常运行时无同时为高。
- [x] 三组 P/N 死区均约 1µs，且方向一致。
- [x] 三组周期一致，更新行为符合配置。
- [x] STOP 后六路均为低。
- [x] 复位/重新上电无非预期脉冲。
- [x] 重复启停无残留输出或异常窄脉冲。
- [x] 保存实测数据与示波器证据（代表性照片3张及屏幕读数；WH已测无图，未提供CSV）。
