# V00-HW-002：LKS32MC071 + FN550-90K 硬件验证清单

- Milestone：V0.0
- Status：NOT RUN
- 硬件基线：LKS_EVB_MCU071CBT8_V1.0 + LKS_EVB_MVPOWPRE_V5.0（两份原理图均为第 1 页电路图）
- 电机：FN550-90K、三相三线、1 对极、无 Hall
- 工作电源条件：用户设备最高 32V，实际测试点与限流阈值等待硬件检查后确定

## A. 完全断电：被动检查（第一优先级）

- [ ] MTR-001 测三组线间电阻；记录表计、温度和单位。
- [ ] MTR-002 测三组线间电感；记录 LCR 频率、电平、转子位置。
- [ ] 核实实物板卡型号和 MCU 型号与已提交原理图匹配。
- [ ] 核实电机相端和 P1/P2 连接器的物理针脚，重点是六路 HIN/LIN。
- [ ] 核实 P2-5、P2-18 两个跨板标签不一致的物理连接。
- [ ] 核实 P5/P6/P7 采样选择连接、R15/R16/R17 和 R69 实装情况。
- [ ] 核实功率输入端极性、接地与储能电容放电路径。

## B. 先不接电机：低能量上电与 PWM

- [ ] 确认适用 DC 输入电压范围和辅助电源额定值。
- [ ] 使用符合板卡范围的限流、隔离 DC 电源，保持功率级禁止输出。
- [ ] 测电源静态输入电流、+15V 与 +5V 电源和纹波。
- [ ] MCU 复位、启动和停止时六路 MOS Gate 都处于明确安全状态。
- [ ] 确认六路 HIN/LIN、死区以及同步更新是否满足要求。
- [ ] 接地式示波器仅以已确认的安全地为参考，不把地夹连接到半桥浮动开关点。

## C. 模拟采样与逐波保护

- [ ] 验证 PU/PV/PW 与 P0.13/P0.12/P0.11 ADC 映射一致。
- [ ] 使用隔离且限幅的低压信号验证三相分压与采样比例。
- [ ] 验证 Vol_ADC 与 P2.9 的实际采样系数。
- [ ] 读取并检查 OPA 增益、偏置和内部比较器路由。
- [ ] 核实 OC 的信号来源、比较器配置和 MCPWM Break/Driver 关断通路。
- [ ] 使用受控逻辑级故障注入验证无 CPU 参与的快速关断。
- [ ] 实测关断延迟和关断后的 Gate 状态。
- [ ] 验证故障恢复不会非预期自动重启。

## D. 电机验证（必须完成 A～C 安全门槛后）

- [ ] 电机夹具、防护罩、禁装切削附件已准备。
- [ ] 电源电压和电流限值有计算/额定值依据；不直接 32V 满功率。
- [ ] 测试初始 ALIGN 及六步开环换相，观察输入电流、相端波形与电机响应。
- [ ] 记录三相 BEMF 在不同低速档的波形和过零事件。
- [ ] BEMF 有效性与换相同步后，才允许进入闭环接管。

## 放行条件

满足 A/B/C 全部关键安全项目并形成证据后才可进入 V0.1 功率试验。若硬件 OC 不能实现逐波关断，应标记 BLOCKED 并记录改动方案，不应默认为软件中断实现等效保护。
