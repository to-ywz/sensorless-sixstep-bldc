# A5 固件操作与观测目标（2026-11-12）

- Status: IMPLEMENTED / SOFTWARE TESTED / NEW FIRMWARE BENCH NOT RUN
- Macro: `BENCH_TEST_GATE_DRIVER`；主目标 `Linko 07x Project`，与A1～A4宏互斥。
- Scope: 一次只测试一个相的栅极，无六步换相。默认全部关断，无自动启动/重复。
- 前置：电机断开、主母线不接电源，P3摘掉；DM_In独立供电；实测母线0 V。5V不得与J-Link供电输出未经确认并联。
- 这份程序没有母线ADC联锁、VBS自动测量或CMP硬件过流保护。不得连接有电母线运行。

## 一、烧录与默认状态

先关闭驱动电源，重新加载Keil工程，Rebuild/下载主目标。仅定义A5宏；此前已打开的Keil工程可能仍缓存A4配置，须确认Define。随后按已确认方法独立供电，检查15V/5V及母线0V。不开START时P低/N高，三只低侧VGS应约0 V。

## 二、Watch变量

| 变量 | 含义 |
|---|---|
| `g_a5_phase` | 0=U、1=V、2=W，默认U |
| `g_a5_test` | 0=低侧限时保持（默认）；1=预充后高侧PWM短包 |
| `g_a5_command` | 写1执行一次；写2停止；读取后清零。实体START/STOP也可用 |
| `g_a5_bootstrap_checked` | 测过对应相VB−VS后才置对应位：U=1、V=2、W=4，可按位组合；默认0，故高侧默认不能运行 |
| `g_a5_state` | 0关断、1低侧保持、2预充、3全关间隔、4高侧短包 |
| `g_a5_fault` | 0无错、1非法输入/状态、2未确认自举、3后端拒绝、4运行中改配置、5预充/间隔严重超时 |
| `g_a5_completed` | 正常结束的测试次数；STOP中断不增加 |

这些是台架操作参数和状态，不是权限确认，也不是硬件传感器。复位会清除自举确认位。运行中更改相位、模式或自举确认位会关断，必须再次执行才开始。

## 三、先做低侧：只开一个下管

停机设 `phase=0`、`test=0`，按START或command=1：U下管开启，U上管及其它相都关闭；5秒后自动关闭。V/W同理；可以提前STOP。保持START不会重复或延长测试。

测量目标：检查LIN低→本相低侧VGS接近驱动电压、其余VGS保持关断；LIN高/STOP→本相VGS回0。不再输出其它相高侧PWM，便于排除互相干扰。

沿用已核对的两通道方法：相同×10设置，两地夹接同一个GND，C1探针Gate、C2探针Source，Math=C1−C2。不得把通道地夹分别接到Source、PGND/GND；Math不提供电气隔离。普通万用表亦可在其量程/隔离条件下测静态VGS。

触发可选本相LIN下降沿（约2.5 V）或低侧VGS上升沿。5秒限时是软件调度值，不是CPU故障下仍保证的硬件关断时限。

## 四、自举检查：仍只开下管，不启动上管

高侧开关需要VB相对VS的浮动电源。利用上一项本相下管保持5秒的窗口，用具备相应浮动测量能力的万用表测驱动器VB−VS：U1/U2/U5分别对应U/V/W，手册针脚VB=8、VS=6，实际先核实丝印和定位，避免探针短接相邻脚。

目标：确认本相低侧拉低VS后，自举能充电。LKS560建议VB−VS为10～20 V；本轮建议至少11 V留出欠压裕量且不超过20 V，约15 V驱动供电时一般接近扣除充电压降后的电压。未建立时停在本项排查，不因无波形而给母线上电。

确认某相后，停机时在bootstrap_checked中置该相位；它仅记录操作者测量结果，程序不能证实VBS实际仍有效。

## 五、高侧单次短包：暂不直接执行，先确认测量接法

相位不变、停机设 `test=1`，且对应自举确认位置1。按一次START后程序依次：

```text
本相低侧导通1 ms（预充）
→ 所有桥臂关断50 µs
→ 仅本相高侧输出约10 kHz、250‰ PWM，持续200 µs
→ 所有桥臂关断，等待下一次明确命令
```

其它相全程关闭，本相低侧在高侧短包期间也关闭。每段切换还包含共享后端的关断/装载等待，实际间隔不等于常量精确值。1 ms/50 µs/200 µs是待验证的台架初值，不是最终电机驱动参数；200 µs相当于约2周期，也可能含首末截断，不能以软件短包保证完整脉冲数。

**目标：** 看预充是否建立高侧电源、首个高侧脉冲是否能实际抬升Gate相对Source，结束后是否回到关断，不是为了验证母线功率开关。

母线0V时可评估使用两只普通探头相减，但条件是每通道对GND的实际电压/瞬态都在探头和示波器额定范围内、倍率及延迟匹配可接受、两地夹都只接同一GND。C1=本相高侧Gate，C2=本相Source/VS，Math=C1−C2；普通探头地夹绝不能接VS。不能仅因Math差值小就忽略单通道共模过压。若上述条件未确认，不执行高侧短包，保留待测，不要求购买新设备来强行推进。

可先仅核心板供电、驱动关闭，按本相HIN上升沿捕获验证程序时序；实际VBS未测时只用于软件/引脚观察，不能把置确认位当作VBS已测。之后驱动供电测试时，触发源可选高侧Gate对GND的上升沿，单次采集、100 µs/div起步，保留前触发记录；观察完再放大到合适时基检查边沿。为了同时比较上下侧VGS，两个探头不能覆盖所有量，可重复同一单次流程分组测量。

STOP在任何阶段都优先；RUN在活动阶段不会延长包。预充/全关间隔超时超过1 ms时程序放弃高侧输出。所有截止都是轮询实现，CPU停顿/卡死可能延长阶段，不能替代硬件保护；调试暂停后先STOP再重新开始，不能用断点暂停期间波形作验收。

## 六、A4与A5的完成边界

A4混合输出缺陷及三相/低侧功能回归已有用户确认；原计划中的逐扇区100 ms±1 ms、STOP延迟等未量化项目仍在记录中，不虚构成已完成。需要A4时取消A5宏，仅定义 `BENCH_TEST_SIXSTEP_LOGIC`。

A5新入口先验收：默认全关→三相低侧单独开启/关闭→STOP/非法参数→自举电压→有条件的高侧短包。旧A4下低侧正常结果不自动等同于新A5程序已实测。本轮不接电机，不恢复母线，不关闭CMP1保护及高侧栅极的未测项目。
