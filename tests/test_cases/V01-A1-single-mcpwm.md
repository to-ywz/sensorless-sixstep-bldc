## 硬件映射

| 信号 | MCU 引脚 | 功能 | 有效电平 |
|---|---|---|---|
| START1 | P2.11 | 启动 PWM | 低有效 |
| STOP1 | P2.12 | 停止 PWM | 低有效 |
| CH0P / UP | P1.4 | 单路 PWM 输出 | 高脉冲 |
| 其余功率控制脚 | P1.5～P1.9 | 测试期间保持 GPIO 低电平 | 低 |

START1、STOP1 外部各有 10kΩ 上拉至 +5V 和 100nF 对 GND。软件配置为输入、无内部上下拉。按下时应接近 0V，松开时应接近 +5V。

## 启用方式

1. Keil 主目标选择 `Linko 07x Project`，不要选 `_ac6`。
2. 在 Keil「Options for Target → C/C++ → Define」添加 `BENCH_TEST_MCPWM_SINGLE`。该宏默认不启用；未定义时运行 A0 心跳程序。
3. Rebuild All，确认 0 Error；下载本次生成的 HEX。
4. 只给控制板安全逻辑供电。确认功率母线断电，电机断开。
5. 上电后先测 P2.11、P2.12：松开接近 +5V，按下接近 0V。
6. 示波器地夹接已确认的逻辑 GND，探头测 P1.4。不要将地夹接到开关节点或不确定的功率地。

## A1 当前 PWM 配置

当前单路输出配置：

- MCPWM 时钟源：系统时钟，板级初始化选择 48MHz RC。
- MCPWM 分频：`CLK_DIV = 0`，不分频。
- 时基：`TH0 = 2400`。
- CH0 比较门限：`TH00 = -600`，`TH01 = +600`。
- CH0 工作模式：中心对齐。
- CH0N：由 `CH0_NS = 1`、`CH0N_SCTRLN = LOW` 固定为低。
- CH0P：由 MCPWM 计数器产生，输出至 P1.4。
- **`IO0_PPE = DISABLE`：关闭 CH0 的 P/N 推挽交替输出。A1 只观察 CH0P，不需要推挽交替。**
- PWM 输出使能由 START1/STOP1 控制。

按理想 48MHz 时钟估算，中心对齐频率约为：

`f = 48MHz / (2 × 2400) = 10kHz`

`TH00=-600`、`TH01=+600` 对应预期高脉冲宽度约 25µs，目标占空比约 25%。内部 RC 时钟存在误差，实际值以示波器测量为准。

## 本轮问题与修改依据

修改前示波器测得：

- 频率：5.0359kHz
- 正占空比：12.6%
- 推算高脉冲宽度：约 25µs

代码当时设置 `IO0_PPE = ENABLE`。LKS32MC07x MCPWM 手册说明：中心对齐推挽模式下，第一个周期由 P 通道输出，第二个周期由 N 通道输出。由于本测试只观察 CH0P，P 通道脉冲重复频率可能变为基准频率的一半，按整个重复周期计算的占空比也相应减半。

因此本轮只将 `IO0_PPE` 改为 `DISABLE`，其余时钟、计数周期和比较门限保持不变。修改后的实测结果为 10.086kHz、24.8%，与修改前约 5.0359kHz、12.6% 的结果形成约 2 倍关系，**已通过实测确认：此前观察 CH0P 时，推挽交替输出使 CH0P 脉冲重复频率减半，按完整重复周期计算的占空比也减半。**

## 按键行为

- START1（P2.11，低有效）：检测到稳定按下后产生一次启动事件；按住不重复触发。
- STOP1（P2.12，低有效）：主循环检测到低电平后关闭 PWM；STOP 优先于 START。
- 若上电时 START1 已按下，不会自动启动；必须先松开再重新按下。
- STOP1 是软件轮询控制，不是独立硬件急停或硬件故障保护。

## 本轮测试步骤

1. 确认逻辑供电正常、功率母线断电、电机断开。
2. 上电后确认 P1.4 为低电平，PWM 默认关闭。
3. 按 START1，测量 P1.4 的频率、正占空比和高电平脉宽。
4. 松开 START1，确认 PWM 保持输出，不会因按键松开而自动停止。
5. 按 STOP1，确认 PWM 停止且 P1.4 恢复稳定低电平。
6. 同时按住 START1 和 STOP1，确认 STOP 优先、PWM 保持关闭。
7. 观察 P1.5～P1.9，确认始终保持低电平。
8. 检查启动、停止和复位瞬间是否出现异常窄脉冲。
