# V01-A1 — 单路 MCPWM 输出实验（无功率驱动）

- Status: **CODE STAGED / BUILD NOT VERIFIED / HARDWARE NOT TESTED**
- 前置条件：A0 的 P1.4～P1.9 上电/复位无异常高脉冲已确认；不接 FN550-90K，功率板主母线断电。
- 目的：只验证 MCU P1.4/CH0P PWM 输出的时钟、固定占空比、按键启停及引脚切换波形。不测试三相互补、驱动电路或逐波过流。\n- 按键映射：START1=P2.11（低有效）；STOP1=P2.12（低有效）。两路外部 10kΩ 上拉至 +5V、100nF 对 GND。

## 启用方式（默认关闭）

1. Keil 主目标使用 `Linko 07x Project`（不是 `_ac6`）。
2. 主目标的 Keil `LK_StdPeriph.uvprojx` **已经引用** `firmware/tests/bench/test_mcpwm_single.c`，并新增了 Include Path `..\..\..\tests\bench`。拉取最新提交后先 Rebuild All，确认默认 A0 模式依然能编译。不要把该源文件重复加入工程。
3. 在 Keil **Options for Target → C/C++ → Define** 中添加 `BENCH_TEST_MCPWM_SINGLE`（编译器宏，**默认没有开启**）；未定义该宏时固件仍为 A0 心跳程序。
4. Rebuild All，确认编译 0 Error；如有 warning 保存全文。
5. 保证外部主功率级没有电源且电机断开；只给控制板安全逻辑电源。
6. 示波器 CH1：P1.4 对已确认的逻辑 GND。触发设置为上升沿，测量 PWM 频率、占空比、脉冲高电平宽度。
7. 程序当前会在 PWM 启用与关闭状态之间周期性交替（间隔为非校准的软件延时），方便观察启停时是否出现毛刺。同时观察 P1.5～P1.9 是否始终为低。
8. 删除 Define `BENCH_TEST_MCPWM_SINGLE` 并重新编译可恢复 A0。

## 按键行为\n\n- START1（P2.11，低有效）：连续稳定按下约 20 个扫描周期后产生一次启动事件；按住不重复触发。\n- STOP1（P2.12，低有效）：检测到低电平即请求关闭 PWM，不等待 START 消抖；STOP 优先。\n- 若上电时 START1 已被按住，不会自动启动；必须松开后重新按下。\n- PWM 占空比固定为初始测试值约 25%，本轮两个按键只负责 START/STOP，不负责调占空比。\n- STOP1 由主循环轮询处理，只是 A1 软件台架控制，不等同于硬件急停、CMP/FAIL 保护。\n\n## 预期值（必须以测量为准）

按时钟 48MHz、中心对齐 2400 刻度粗估：PWM 频率约 **10kHz**。TH00=-600、TH01=+600 预期形成约 25% 开窗；具体占空比和电平极性应根据手册逻辑与示波器确认，不能仅以配置值认定正确。

- [ ] START1 可启动 PWM，STOP1 可停止 PWM，STOP 优先。\n- [ ] PWM 关闭期间 P1.4 为稳定低电平，重新使能无异常窄脉冲。
- [ ] P1.5～P1.9 始终保持低电平。
- [ ] 上电、复位、测试模式切换未出现异常高脉冲。
