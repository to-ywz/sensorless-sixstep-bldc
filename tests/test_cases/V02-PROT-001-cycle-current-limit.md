# V02-PROT-001 — 逐波过流硬件关断验证

- Requirement ID: PROT-CYCLE-001
- Milestone: V0.2
- Status: NOT IMPLEMENTED / NOT RUN
- 本文件只定义**最终逐波过流验收**；当前先执行[V0.2总计划](V02-PLAN-000-workplan.md)的V02-00/01逻辑级阶段。内部CMP1 RAW→FAIL1通路测试只是其子集，不得当作本用例全部PASS。

## Objective
验证过流比较器/驱动器保护能否通过硬件路径快速关断功率输出。

## Preconditions
- 已从原理图确认保护链路。
- 已核对器件安全工作区和测试限流。
- 使用受控、低能量、可重复的测试方法。
- 禁止通过直接短接母线制造故障。

## Procedure
1. 记录正常电流和比较器输入。
2. 使用经审核的**低能量模拟信号**逐步跨越保护阈值；任何带母线功率试验必须等待A5安全门槛与V02逻辑级测试通过。
3. 同步观测电流、比较器输出、PWM/Gate 和故障标志。
4. **先测试锁存与显式清故障**；仅在失效安全的门槛通过后，再另行测试逐PWM周期恢复，二者不能混为一项。
5. 验证保护清除条件。

## Expected Result
硬件链路无需等待主循环即可将输出置于正确的LKS560安全输入态（HIN=0/LIN=1）；经真实模拟链及六扇区采样窗口确认后，才具备讨论逐波限流阈值与周期性恢复的依据。

## 首轮无实际电流的子阶段（2026-11-15）

先准备内部CMP1 RAW→FAIL1→CH0/1/2受控注入验证，不接主母线与电机；控制板逻辑引脚必须与未供电预驱输入可靠隔离。候选内部DAC/REF方法须核实模拟参数；不飞线、不用真实大电流。本子阶段不代替完整逐波电流限流，见[内部保护链计划](V02-PROT-001-internal-path-plan.md)。
