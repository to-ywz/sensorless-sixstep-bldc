# V02-PROT-001 — 逐波过流硬件关断验证

- Requirement ID: PROT-CYCLE-001
- Milestone: V0.2
- Status: NOT RUN

## Objective
验证过流比较器/驱动器保护能否通过硬件路径快速关断功率输出。

## Preconditions
- 已从原理图确认保护链路。
- 已核对器件安全工作区和测试限流。
- 使用受控、低能量、可重复的测试方法。
- 禁止通过直接短接母线制造故障。

## Procedure
1. 记录正常电流和比较器输入。
2. 使用经审核的注入方式逐步跨越保护阈值。
3. 同步观测电流、比较器输出、PWM/Gate 和故障标志。
4. 验证故障锁存/自动恢复行为。
5. 验证保护清除条件。

## Expected Result
硬件链路无需等待主循环即可将功率输出置于安全态；阈值和恢复行为与设计一致。
