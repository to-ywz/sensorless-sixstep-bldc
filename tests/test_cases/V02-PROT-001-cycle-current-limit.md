# V02-PROT-001 — 逐波过流硬件关断验证

- Requirement ID: PROT-CYCLE-001
- Milestone: V0.2
- Status: NOT IMPLEMENTED / NOT RUN
- 本文件只定义**最终逐波过流验收**；当前先执行[V0.2总计划](V02-PLAN-000-workplan.md)的V02-00/01逻辑级阶段。内部CMP1 RAW→FAIL1通路测试只是其子集，不得当作本用例全部PASS。

## Objective

**最终验收目标：一级CBC逐波限流 + 二级严重故障锁存。** 一级在有效电流超过阈值时由硬件截断**当前PWM周期有效导通**，且只能在满足条件的**后续安全周期边界**恢复；二级对严重、持续或不可信的故障锁存全部危险输出，清故障与重新RUN必须显式执行。两级触发源、阈值、硬件资源如何实现尚待V02-00/03核实，不默认一条CMP1/FAIL1就可同时完成。

第一阶段先测故障锁存与异步关断链，只是测试依赖关系，不代表将锁存选为正常过流控制方式。

## Preconditions
- 已从原理图确认保护链路。
- 已核对器件安全工作区和测试限流。
- 使用受控、低能量、可重复的测试方法。
- 禁止通过直接短接母线制造故障。

## Procedure
1. 记录正常电流和比较器输入。
2. 使用经审核的**低能量模拟信号**逐步跨越保护阈值；任何带母线功率试验必须等待A5安全门槛与V02逻辑级测试通过。
3. 同步观测电流、比较器输出、PWM/Gate 和故障标志。
4. **先测试锁存与显式清故障**；仅在失效安全的门槛通过后，再另行测试逐PWM周期恢复，二者不能混为一项。
5. 验证保护清除条件。

## Expected Result

**分两组独立验收，不得互相代替：**

| 编号 | 应证明的结果 | 未达标时 |
|---|---|---|
| **CBC-01 本周期截断** | 已确认有效的模拟电流条件触发后，硬件无需等待CPU便取消当前PWM有效段，并在**同一周期内保持关闭** | CBC = NOT VERIFIED |
| **CBC-02 后续周期恢复** | 比较器/FAIL源已处于允许条件且不存在二级故障时，只能在定义的安全PWM边界恢复；持续超限不发生失控反复开通 | CBC = NOT VERIFIED |
| **CBC-03 六扇区保护覆盖** | 三相真实采样/OPA/CMP通路及PWM导通/续流/消隐窗口在六个扇区均可检测危险过流 | V0.2 整体不能PASS |
| **LATCH-01 严重故障锁存** | 高优先级故障切断输出，故障存在或仅撤销但未显式清故障时均不能重启；必须满足条件后明确RUN | 二级保护 = NOT VERIFIED |
| **LATCH-02 优先级/升级策略** | CBC连续受限或关键故障按经验证规则升级锁存；锁存优先于CBC的周期性恢复 | 二级保护 = NOT VERIFIED |

阈值、升级次数、故障掩码、自动恢复机制与模拟资源占用必须实核，本文件不预设实现器件能力。第一阶段逻辑P0–P3通过最多证明内部硬件关断和锁存状态，不代表CBC-01/02或真实电流限制通过。

## 首轮无实际电流的子阶段（2026-11-15）

先准备内部CMP1 RAW→FAIL1→CH0/1/2受控注入验证，不接主母线与电机；控制板逻辑引脚必须与未供电预驱输入可靠隔离。候选内部DAC/REF方法须核实模拟参数；不飞线、不用真实大电流。本子阶段不代替完整逐波电流限流，见[内部保护链计划](V02-PROT-001-internal-path-plan.md)。
