# V04-BEMF-001 — 六扇区 BEMF 过零检测

- Requirement ID: SYS-BEMF-001..005
- Milestone: V0.4
- Status: NOT RUN

## Objective
验证每个换相扇区的悬空相选择、过零极性、消隐和去磁判断。

## Preconditions
- V0.2 采样链路完成标定。
- V0.3 电机可在受控开环状态运行。
- 示波器差分测量方法和参考点确认。

## Procedure
1. 逐扇区记录三相端电压、参考电压和检测信号。
2. 标注换相瞬间、振铃区间、去磁区间和真实过零。
3. 验证悬空相选择及过零极性。
4. 改变转速，观察消隐和滤波参数的适用性。
5. 统计误触发和漏检。

## Expected Result
六个扇区的检测相与极性正确；换相振铃不造成错误事件；有效过零时间可重复。
